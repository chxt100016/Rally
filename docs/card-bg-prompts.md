# 约球卡片背景样式方案

## 最终方向

约球卡片不再使用真实照片或 AI 生成图，也不再通过七牛加载背景图片。

背景由小程序前端直接使用 **CSS 渐变 + 极淡 SVG 球场线稿 + 可选雨丝**渲染：

- 材质决定主色：硬地蓝绿、红土橙红、草地绿色。
- 时段决定色温：白天明亮、黄昏暖紫、夜晚蓝青。
- 天气只保留晴/雨：晴天使用纯渐变；雨天叠加轻量斜雨丝和少量冷色调。
- 室内忽略时段和天气，按材质使用固定渐变。
- 不绘制天空、云、看台、球员等复杂场景，避免小卡片信息过载。
- 不加载图片，避免网络请求、缓存、裁切和清晰度问题。

## 后端样式标识

`backgroundImage` 字段暂时沿用原字段名，但返回值已经变为前端背景样式标识，不是图片 URL。

### 室外

格式：

```text
{surface}-{slot}-{weather}
```

取值：

- surface：`hard` / `clay` / `grass`
- slot：`day` / `dusk` / `night`
- weather：`clear` / `rain`

示例：

```text
hard-day-clear
hard-dusk-rain
clay-night-clear
grass-day-rain
```

### 室内

格式：

```text
indoor-{surface}
```

示例：

```text
indoor-hard
indoor-clay
indoor-grass
```

## 降级规则

- 场地材质为空 → `hard`
- 室内室外为空 → `outdoor`
- 天气为空 → `clear`
- 无 courtId 的地图自由选点活动 → `hard` + `outdoor`
- 开球时间必须传入，用于计算白天/黄昏/夜晚

当前天气模块尚未接入，后端传入 `null`，因此暂时统一降级为晴天。天气模块接入后，查询时传入最新预报即可，不需要修改 meetup 表。

## 时段规则

- 白天：06:00（含）至 17:00（不含）
- 黄昏：17:00（含）至 19:00（不含）
- 夜晚：19:00（含）至次日 06:00（不含）

## 前端视觉规则

- 背景 full-bleed 铺满整张卡片。
- 不使用泛白遮罩、不使用四周暗角。
- SVG 球场线稿仅作为低透明度纹理，不与文案竞争。
- 雨天只添加细雨丝，不增加云等复杂天气插画。
- 白色文案使用轻微文字阴影保证可读性。
- 球场名最多两行并固定预留两行高度；其他字段均单行省略。
- 普通卡片固定高度 `246rpx`，compact 卡片固定高度 `210rpx`。
