## 一句话价值

为运营手工录入一个高德抓不到的球场，直接对用户可用。

## 核心概念

- 球场  可供网球活动选择的线下场地，包含位置、环境和联系资料。
- 手工录入球场  由运营在后台逐条填写而不是从高德抓取得到的球场，来源记为系统录入，没有三方来源编号。
- 球场业务编号  球场在平台内的唯一标识，新增时生成，之后不再变更。

## 业务对象

### 新增指令

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `name` | 字符串 | 是 | 球场名称，最长 128 字符。 |
| `cityCode` | 字符串 | 是 | 所属城市编码，取自平台城市名录的六位城市编码。 |
| `alias` | 字符串列表 | 否 | 球场别名，存入时以英文逗号连接，连接后最长 128 字符。 |
| `address` | 字符串 | 否 | 球场详细地址，最长 256 字符。 |
| `lng` | 小数 | 否 | 球场经度，取值范围 -180 到 180。 |
| `lat` | 小数 | 否 | 球场纬度，取值范围 -90 到 90。 |
| `districtCode` | 字符串 | 否 | 所属区域编码，取自平台区县名录。 |
| `remark` | 字符串 | 否 | 球场备注，最长 255 字符。 |
| `type` | 枚举 | 否 | 球场环境，取值 `INDOOR` 或 `OUTDOOR`。 |
| `surface` | 枚举 | 否 | 场地材质，取值 `HARD`、`CLAY` 或 `GRASS`。 |
| `tags` | 字符串列表 | 否 | 球场标签，存入时以英文逗号连接，连接后最长 512 字符。 |
| `rating` | 字符串 | 否 | 评分展示值，存入球场扩展资料。 |
| `cost` | 字符串 | 否 | 费用展示值，存入球场扩展资料。 |
| `opentime` | 字符串 | 否 | 开放时间展示值，存入球场扩展资料。 |
| `tel` | 字符串 | 否 | 联系电话，存入球场扩展资料。 |
| `status` | 枚举 | 否 | 球场状态，取值 `COLLECTED`、`ACTIVE` 或 `DISABLED`；不填时为 `ACTIVE`。 |

### 球场（`rally_court`）

本服务写入的字段：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `biz_id` | `VARCHAR(32)` | 是 | 球场业务编号，新增时生成。 |
| `source_id` | `VARCHAR(128)` | 否 | 三方来源编号，手工录入球场为空。 |
| `name` | `VARCHAR(128)` | 是 | 球场名称，取指令中的名称。 |
| `alias` | `VARCHAR(128)` | 否 | 球场别名，由指令中的别名列表以英文逗号连接；列表为空时为空。 |
| `address` | `VARCHAR(256)` | 否 | 球场详细地址。 |
| `lng` | `DOUBLE` | 否 | 球场经度。 |
| `lat` | `DOUBLE` | 否 | 球场纬度。 |
| `city_code` | `VARCHAR(32)` | 是 | 所属城市编码。 |
| `district_code` | `VARCHAR(32)` | 否 | 所属区域编码。 |
| `city_name` | `VARCHAR(64)` | 否 | 城市名称，按城市编码在城市名录中取得。 |
| `district_name` | `VARCHAR(64)` | 否 | 区域名称，按区域编码在区县名录中取得；区域编码为空时为空。 |
| `remark` | `VARCHAR(255)` | 否 | 球场备注。 |
| `type` | `VARCHAR(32)` | 否 | 球场环境。 |
| `surface` | `VARCHAR(32)` | 否 | 场地材质。 |
| `tags` | `VARCHAR(512)` | 否 | 球场标签，由指令中的标签列表以英文逗号连接；列表为空时为空。 |
| `ext_data` | `TEXT` | 否 | 球场扩展资料，含 `rating`、`cost`、`opentime`、`tel`、`pinyin`、`pinyinInitial`；单项资料缺失时不写入该项。 |
| `source` | `VARCHAR(32)` | 是 | 来源，固定为 `SYSTEM`。 |
| `status` | `VARCHAR(32)` | 是 | 球场状态，取指令中的状态；不填时为 `ACTIVE`。 |
| `meetup_count` | `INT` | 是 | 约球次数统计，新增时为 0。 |

`status` 的取值：

| 取值 | 业务含义 |
|---|---|
| `COLLECTED` | 已收录，待审核；不出现在用户端球场清单中。 |
| `ACTIVE` | 可用；出现在用户端球场清单中。 |
| `DISABLED` | 已停用；不出现在用户端球场清单中。 |

### 新增结果

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `courtId` | 字符串 | 是 | 新增球场的业务编号。 |

## 状态机

无

## 主流程

触发源：运营在后台发起 HTTP 新增；终态：一条新球场已写入球场库，并交付球场业务编号。

1. 接收球场资料。
2. 在城市名录中确认城市编码存在，取得城市名称；填了区域编码时在区县名录中取得区域名称。
3. 生成球场业务编号。
4. 把别名列表与标签列表分别以英文逗号连接，把评分、费用、开放时间、联系电话，以及球场名称的拼音与拼音首字母整理为扩展资料。
5. 写入球场，来源记为系统录入，三方来源编号留空，约球次数记为 0，状态取指令中的状态或默认为可用。
6. 交付新增球场的业务编号。

## 分支与异常

| 什么情况 | 怎么处理 | 对外提示 | 做了一半的怎么收场 |
|---|---|---|---|
| 球场名称为空或只含空白字符 | 拒绝新增 | `name: 请填写球场名称` | 未修改任何业务数据。 |
| 城市编码为空或只含空白字符 | 拒绝新增 | `cityCode: 请选择城市` | 未修改任何业务数据。 |
| 城市编码在城市名录中不存在 | 拒绝新增 | `城市不存在` | 未修改任何业务数据。 |
| 区域编码在区县名录中不存在 | 拒绝新增 | `区域不存在` | 未修改任何业务数据。 |
| 球场环境、场地材质或球场状态不是允许的取值 | 拒绝新增 | `参数不正确` | 未修改任何业务数据。 |
| 经度或纬度超出取值范围 | 拒绝新增 | `参数不正确` | 未修改任何业务数据。 |
| 名称、别名、地址、备注或标签超出长度上限 | 拒绝新增 | `参数不正确` | 未修改任何业务数据。 |
| 球场库写入失败 | 新增失败 | `系统异常，请稍后重试` | 未修改任何业务数据。 |

## 业务边界

本服务负责按运营填写的资料新增一条手工录入球场，到交付球场业务编号为止。服务只对运营开放，不面向普通用户。服务不负责查重，不负责从高德补全球场资料，不负责球场的编辑与停用，不负责球场审核。

## 遗留与待定

- 新增时不做重名或就近查重，同一处球场可以被反复录入；是否需要按名称或坐标查重，应由产品与运营确认。
- 手工录入球场的 `source_id` 为空，后续抓取不会把它与高德的同一处球场关联起来，可能出现重复球场；两者怎么归并，应由产品与运营确认。
- 新增时球场状态默认为 `ACTIVE`，即录即对用户可见，未经过 `COLLECTED` 待审核环节；手工录入是否需要审核，应由产品与运营确认。
- 球场名称的拼音与拼音首字母由系统按名称生成，多音字场景的正确性无法保证，也没有提供人工修正入口；是否需要允许运营手工填写拼音，应由产品确认。
- `alias` 与 `tags` 按英文逗号连接后写入，未定义单项内容本身含逗号时的规则，应由产品与场地数据负责人确认。
- 新增球场没有记录操作人和操作时间，无法追溯是谁录入的；是否需要操作留痕，应由产品与运营确认。
