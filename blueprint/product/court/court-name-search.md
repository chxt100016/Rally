## 一句话价值

按城市和关键词向用户交付匹配球场。

## 核心概念

- 球场  可供网球活动选择的线下场地，包含位置、环境和联系资料。
- 可用球场  状态为可用、允许出现在球场清单中的球场。

## 业务对象

### 球场搜索结果

| 业务名称 | 描述 | 取值说明 |
|---|---|---|
| 球场编号 | 唯一标识搜索结果中的球场。 | — |
| 球场名称 | 球场的正式名称；名称和别名均可匹配关键词。 | — |
| 球场别名 | 球场可供识别和搜索的其他名称。 | — |
| 场地位置 | 球场地址、经纬度、所属城市和区县。 | — |
| 球场环境 | 表示球场位于室内还是室外。 | 室内：室内球场；室外：室外球场。 |
| 球场标签 | 用于描述球场特点的标签列表。 | — |
| 球场资料 | 球场备注、评分、费用、开放时间和联系电话。 | — |
| 球场状态 | 本服务只交付当前可用的球场。 | 已收录：已进入名录但等待审核；可用：可以进入搜索结果；已停用：不进入搜索结果。 |

## 交付内容

类型: 查询类

向消费者交付当前业务事实的查询结果；身份与状态造成的展示差异，以及列表的排序、分页和无结果口径，以本节下列规则及主流程、分支与异常为准。

## 主流程

触发源：接口（用户或匿名访问者）；终态：交付指定城市中名称或别名匹配关键词的可用球场列表，不改变任何业务对象状态。

1. 接收搜索城市和名称关键词，确认城市编码已填写且关键词至少包含两个字符。
2. 在指定城市中筛选状态为可用的球场。
3. 保留正式名称或别名中包含该关键词的球场。
4. 为每个匹配球场交付编号、名称、地点、环境、标签、别名和扩展资料；没有匹配项时交付空列表。

## 分支与异常

| 什么情况 | 怎么处理 | 对外提示 | 做了一半的怎么收场 |
|---|---|---|---|
| 城市编码缺失、为空或只有空白字符 | 不受理搜索 | `cityCode: 请选择城市` | 本服务只读，没有业务对象需要恢复。 |
| 请求正文缺失、为 `null` 或内容无法解析 | 终止搜索 | `系统异常，请稍后重试` | 本服务只读，没有业务对象需要恢复。 |
| 关键词未填写或字符长度少于 `2` | 不查询球场，交付空列表 | 查询成功 | 本服务只读，没有业务对象需要恢复。 |
| 指定城市没有名称或别名匹配的可用球场 | 交付空列表 | 查询成功 | 本服务只读，没有业务对象需要恢复。 |
| 关键词至少两个字符但全部是空白字符 | 不按名称或别名筛选，交付该城市全部可用球场 | 查询成功 | 本服务只读，没有业务对象需要恢复。 |
| 球场的 `alias` 或 `tags` 为空 | 对应结果字段交付空列表，其余资料正常交付 | 查询成功 | 本服务只读，没有业务对象需要恢复。 |
| 球场的 `ext_data` 为空、格式无法识别或缺少某项扩展资料 | 对应的拼音、评分、费用、开放时间或电话交付为空，其余资料正常交付 | 查询成功 | 本服务只读，没有业务对象需要恢复。 |
| 球场资料中的枚举值无法识别，或球场资料读取失败 | 终止搜索 | `系统异常，请稍后重试` | 本服务只读，没有业务对象需要恢复。 |
| 携带的登录凭证缺失或无法验证 | 按匿名访问者继续搜索 | 查询成功 | 本服务只读，没有业务对象需要恢复。 |

## 业务边界

本服务只负责按城市以及球场正式名称或别名交付既有可用球场，到返回匹配列表为止。它不负责按地址、区域、标签或拼音搜索，不负责校验城市是否已开通，不对结果排序、分页或计算总数，不新增、修改、审核或停用球场，也不累计球场活动热度。

## 遗留与待定

| 等级 | 待定的是什么 | 要谁来定 |
|---|---|---|
| P2 | 关键词少于 `2` 个字符直接交付空列表，但未见该最小长度的业务依据；最小长度应由产品确认。 | 产品与场地运营负责人 |
| P2 | 关键词没有去除首尾空白；两个及以上空白字符会交付城市内全部可用球场，预期行为应由产品确认。 | 产品与场地运营负责人 |
| P2 | 关键词中的 `%` 和 `_` 会参与范围匹配而不是按普通字符处理，是否允许该行为应由产品与数据负责人确认。 | 产品与场地运营负责人 |
| P2 | 名称和别名的大小写、全半角及重音字符匹配规则取决于现有数据规则，产品尚未定义统一口径。 | 产品与场地运营负责人 |
| P2 | 搜索没有结果数量上限、分页或明确排序；大城市结果量增长后的交付范围和排序规则应由产品确认。 | 产品与场地运营负责人 |
| P2 | 城市编码不与城市名录核对；不存在的城市与存在但没有匹配球场的城市都会交付空列表，是否需要区分应由产品确认。 | 产品与场地运营负责人 |
| P2 | `total` 当前固定为空，其业务含义以及是否保留该字段待产品确认。 | 产品与场地运营负责人 |
| P2 | `pinyin` 和 `pinyinInitial` 随结果交付但不参与搜索，是否需要支持拼音搜索待产品确认。 | 产品与场地运营负责人 |
| P2 | `rating`、`cost`、`opentime` 和 `tel` 的格式、单位及展示规则未见业务定义，待产品与场地数据负责人确认。 | 产品与场地运营负责人 |
| P2 | `alias` 和 `tags` 直接按英文逗号拆分且不清理单项空白，别名和标签的录入规范待产品与场地数据负责人确认。 | 产品与场地运营负责人 |
| P2 | 关键词没有最大长度限制，允许的最大搜索长度待产品确认。 | 产品与场地运营负责人 |
