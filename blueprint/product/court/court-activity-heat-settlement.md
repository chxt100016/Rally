## 一句话价值

每日将昨日合格约球累计为球场活动热度。

## 核心概念

- 约球  围绕一次明确时间、场地、人数和参与条件组织的网球活动，不只是两人邀约。
- 球场活动热度  球场累计承接的合格已结束约球次数，以 `meetup_count` 表示。

## 业务对象

### 球场活动热度

| 业务名称 | 描述 | 取值说明 |
|---|---|---|
| 球场编号 | 标识本次结算热度的球场。 | — |
| 累计约球次数 | 该球场累计承接的合格已结束约球数量；原值为空时从零开始累计。 | — |
| 本次新增次数 | 昨日结束、已归属该球场且符合场地选择条件的约球数量。 | — |
| 约球状态 | 只有已经结束的约球参与本次结算。 | 草稿：不参与；报名中：不参与；进行中：不参与；已关闭：不参与；已结束：满足其他条件时参与。 |
| 场地选择方式 | 只有选择了已有球场的约球才能归属球场并参与结算。 | 文字搜索：可以参与；地图选择：可以参与；自由填写：不参与。 |

## 状态机

无

## 主流程

每日定时触发；终态：昨日合格约球已累计至各关联球场的活动热度。

1. 确定昨日完整自然日作为本次结算范围。
2. 取得结束时间落在昨日且状态为已结束的约球。
3. 保留通过地图或文本搜索选择、且已关联球场的约球。
4. 按球场汇总符合条件的约球次数。
5. 将各球场的汇总次数累加到其活动热度。

## 分支与异常

| 什么情况 | 怎么处理 | 对外提示 | 做了一半的怎么收场 |
|---|---|---|---|
| 昨日没有状态为已结束的约球 | 本次结算直接结束 | 无 | 未产生变更 |
| 昨日约球均为自由填写场地或未关联球场 | 不计入任何球场，本次结算结束 | 无 | 未产生变更 |
| 约球在结算时尚未处于 `FINISHED` | 本次不计入 | 无 | 代码未见后续自动补录 |
| `court_id` 找不到对应的 `rally_court.biz_id` | 该约球无法增加任何球场热度 | 无 | 代码未见失败记录或补偿 |
| 读取昨日约球失败 | 本次结算终止 | 无 | 未产生变更 |
| 累加某个球场热度时失败 | 本次结算异常终止 | 无 | 此前已累加的球场未见统一撤销规则 |

## 业务边界

- 负责统计昨日已结束、通过地图或文本搜索选场且已关联球场的约球。
- 负责按球场汇总次数并增加 `rally_court.meetup_count`。
- 不负责把到期约球推进为已结束状态。
- 不负责为自由填写的场地建立球场档案或推断其所属球场。
- 不负责修正历史热度、提供热度排名或解释热度的展示方式。

## 遗留与待定

- 同一自然日重复执行会再次累计同一批约球；是否需要结算标记、去重或纠错机制，需产品与研发确认。
- 昨日约球若在本次结算后才变为 `FINISHED`，代码未见跨日补录；补录口径需产品与运营确认。
- 约球关联不存在的球场时当前静默漏计；是否告警、修复关联或补记热度需运营与研发确认。
- 多个球场依次结算时若中途失败，已生效部分如何核对和补偿未定义，需产品与研发确认。
- “昨日”取运行环境的自然日，业务采用哪个时区未明确，需产品确认。
