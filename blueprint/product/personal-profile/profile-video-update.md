## 一句话价值

让用户修改本人档案视频标题并取得最新个人档案。

## 核心概念

- 个人档案  用户基础资料与网球资料的组合，包含 NTRP、自评状态、评分和展示视频。
- NTRP  用于描述网球水平的等级值，既用于个人展示，也用于约球和赛事准入。
- 核查期  用户修改自评等级后，需要用后续比赛与评价验证新等级的阶段。

## 业务对象

### 展示视频

| 业务名称 | 描述 | 取值说明 |
|---|---|---|
| 视频资源标识 | 标识本人档案中要修改标题的视频，不得为空白。 | — |
| 视频标题 | 本次保存的新标题；空白标题在档案中展示为“未命名”。 | — |
| 展示视频列表 | 视频标题修改后的本人展示视频列表。 | — |
| 档案状态 | 修改视频标题不改变个人档案原有状态。 | 待完善：网球档案尚待完善；正常：档案正常可用；核查期：档案正在核查。 |

## 交付内容

类型: 变更类

成功后按主流程改写或撤销既有业务事实；允许变更的内容、前置状态、对外可见结果与原值留痕，以本节下列规则、业务对象及分支与异常为准。

## 主流程

触发源：接口（用户）；终态：本人档案中目标视频的标题已更新，并向本人交付最新个人档案；档案状态和视频资源不变。

1. 依据当前登录身份确定要修改个人档案的用户本人，并接收目标视频资源标识与新标题。
2. 取得本人的基础资料与网球档案，在本人展示视频列表中查找资源标识精确匹配的视频。
3. 将首个匹配视频的标题替换为新标题，并保存更新后的展示视频列表；其余视频内容和档案状态保持不变。
4. 汇总修改后的基础资料、活动统计、NTRP 等级提示、综合评级和展示视频。
5. 为头像、视频和视频封面形成七牛云限时访问地址，并交付修改后的完整个人档案。

## 分支与异常

| 什么情况 | 怎么处理 | 对外提示 | 做了一半的怎么收场 |
|---|---|---|---|
| 未携带登录凭据，或凭据没有使用约定格式 | 不受理修改 | 登录已过期，请重新登录 | 不读取或修改个人档案。 |
| 登录凭据已过期、签名错误或内容无法验证 | 不受理修改 | 登录凭证无效，请重新登录 | 不读取或修改个人档案。 |
| `key` 缺失、为空或仅含空白 | 拒绝修改 | key: 视频 key 不能为空 | 不读取或修改个人档案。 |
| 登录身份对应的 `user` 记录不存在 | 终止修改 | 登录凭证无效，请重新登录 | 不修改个人档案。 |
| 本人没有 `user_tennis_profile` 记录 | 无法取得可修改的视频列表，终止修改 | 系统异常，请稍后重试 | 不建立档案，不修改任何视频。 |
| `user_tennis_profile.videos` 为 `null` 且档案状态为 `TBC` | 不修改视频，仍交付状态与基础资料 | 修改成功 | 视频列表仍为空；不交付统计、等级、评分和视频。 |
| `user_tennis_profile.videos` 为 `null` 且档案状态为 `NORMAL` 或 `UNDER_REVIEW` | 无法形成返回档案，终止修改 | 系统异常，请稍后重试 | 本次档案保存整体撤回，已有资料保持不变。 |
| `user_tennis_profile.videos` 为空列表 | 找不到目标视频，仍保存并返回未变化的档案 | 修改成功 | 视频列表保持为空。 |
| `key` 在本人视频列表中没有匹配项 | 不修改任何视频，仍保存并返回未变化的档案 | 修改成功 | 已有视频保持不变。 |
| 视频列表中存在多个相同 `key` | 只修改首个匹配项并返回档案 | 修改成功 | 其余同标识视频保留原标题。 |
| 提交的 `title` 为 `null`、空字符串或纯空白 | 将命中视频的标题保存为该值，返回时展示“未命名” | 修改成功 | 已保存标题不自动替换为“未命名”。 |
| `user_tennis_profile.videos` 不是可识别的视频列表 | 无法读取目标视频，终止修改 | 系统异常，请稍后重试 | 不修改个人档案。 |
| 视频列表项的 `key` 为 `null`，且在查找目标前先遇到该项 | 无法继续查找，终止修改 | 系统异常，请稍后重试 | 不修改个人档案。 |
| 档案保存失败 | 终止修改 | 系统异常，请稍后重试 | 本次标题修改整体撤回，已有标题保持不变。 |
| 修改已保存，但基础资料、关注关系、约球、报名或配置读取失败 | 无法形成返回档案，终止修改 | 系统异常，请稍后重试 | 本次标题修改整体撤回，已有标题保持不变。 |
| 非空头像、视频或封面资源无法由七牛云签发访问地址 | 无法形成返回档案，终止修改 | 系统异常，请稍后重试 | 本次标题修改整体撤回，已有标题保持不变。 |
| 非空视频资源标识没有文件扩展名 | 无法形成封面资源标识，终止修改 | 系统异常，请稍后重试 | 本次标题修改整体撤回，已有标题保持不变。 |
| 返回档案所需的数字配置无法识别 | 将对应整数或浮点配置按 `0` 使用，继续交付档案 | 修改成功 | 标题已保存；返回的等级提示、评级或视频限制可能按 `0` 形成。 |
| 发生其他未归类错误 | 终止修改 | 系统异常，请稍后重试 | 本次标题修改整体撤回，已有标题保持不变。 |

## 业务边界

- 本服务只接受当前登录用户修改本人个人档案中的视频标题，不接受指定其他用户，也不能修改他人档案视频。
- 本服务从接收已有视频的资源标识和新标题开始，到保存标题并交付最新个人档案为止；视频标题之外的档案内容和档案状态保持不变。
- 本服务不上传、替换或删除七牛云中的视频文件，也不改变视频资源标识；取得上传授权、登记新视频和删除档案视频分别属于其他业务服务。
- 本服务只在本人的 `user_tennis_profile.videos` 列表内按资源标识查找目标，不以七牛云中是否存在同名资源判断归属。
- 本服务不校验新标题的长度、内容、语言或敏感信息，也不裁剪标题首尾空白。
- 本服务交付完整个人档案，因此会读取基础资料、关注数量、完成约球数量、等级、评分、视频限制和城市名录，但不会借此修改这些对象。
- 本服务交付七牛云限时访问地址，但不保证地址超过一小时后仍可访问。
