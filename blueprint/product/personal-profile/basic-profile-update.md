## 一句话价值

让用户更新本人基础资料并立即取得修改后的个人档案。

## 核心概念

- 个人档案  用户基础资料与网球资料的组合，包含 NTRP、自评状态、评分和展示视频。
- NTRP  用于描述网球水平的等级值，既用于个人展示，也用于约球和赛事准入。
- 核查期  用户修改自评等级后，需要用后续比赛与评价验证新等级的阶段。

## 交付内容

类型: 变更类

成功后按主流程改写或撤销既有业务事实；允许变更的内容、前置状态、对外可见结果与原值留痕，以本节下列规则、业务对象及分支与异常为准。

## 主流程

触发源：接口（用户）；终态：已保存本人提交的非空基础资料，并向本人交付修改后的完整个人档案。

1. 依据当前登录身份确定需要修改的用户本人。
2. 取得本人的现有基础资料；没有对应用户时终止修改。
3. 用本次提交的每个非空字段覆盖对应基础资料，未提交或提交为空值的字段保留原值。
4. 保存修改后的昵称、头像、性别、生日、城市和个人简介。
5. 重新取得修改后的基础资料及已有网球档案，并确定个人档案状态。
6. 交付修改后的基础资料，将头像资源转换为限时访问地址，并按城市编码补充城市名称。
7. 若个人档案正常或处于核查期，汇总关注、粉丝和已完成约球数量，形成 NTRP 提示与综合评级，并交付展示视频及当前限制。
8. 若没有网球档案或档案尚待完善，只交付档案状态和修改后的基础资料。

## 分支与异常

| 什么情况 | 怎么处理 | 对外提示 | 做了一半的怎么收场 |
|---|---|---|---|
| 未携带登录凭据或凭据格式不符合要求 | 不受理修改 | 登录已过期，请重新登录 | 基础资料保持原值。 |
| 登录凭据已过期、签名错误或内容无法验证 | 不受理修改 | 登录凭证无效，请重新登录 | 基础资料保持原值。 |
| 请求体缺失、无法解析，或日期格式无法识别 | 终止修改 | 系统异常，请稍后重试 | 基础资料保持原值。 |
| `gender` 不是 `MALE`、`FEMALE`、`UNDISCLOSED` 之一 | 终止修改 | 系统异常，请稍后重试 | 基础资料保持原值。 |
| 登录身份没有对应的 `user` 记录 | 终止修改 | 用户不存在 | 基础资料保持原值。 |
| 所有修改字段均未提交或均为 `null` | 保留全部原值，仍交付当前个人档案 | 修改成功 | 没有业务资料发生变化。 |
| 某些字段为 `null`、另一些字段有值 | 只保存有值的字段，其他字段保留原值 | 修改成功 | 已提交的有效字段一并生效。 |
| 没有 `user_tennis_profile` 记录 | 完成基础资料修改，返回 `NONE` 和修改后的基础资料 | 修改成功 | 不建立网球档案。 |
| 个人档案状态为 `TBC` | 完成基础资料修改，返回 `TBC` 和修改后的基础资料 | 修改成功 | 不补齐网球档案。 |
| 非空 `cityCode` 在城市名录中不存在 | 无法形成修改后的返回档案，不确认修改成功 | 系统异常，请稍后重试 | 本次基础资料修改不生效。 |
| `user_tennis_profile.status` 不是可识别的大写状态值 | 无法形成修改后的返回档案，不确认修改成功 | 系统异常，请稍后重试 | 本次基础资料修改不生效。 |
| `user_tennis_profile.videos` 不是可识别的视频列表 | 无法形成修改后的返回档案，不确认修改成功 | 系统异常，请稍后重试 | 本次基础资料修改不生效。 |
| 正常或核查期档案缺少形成结果所需的 NTRP、评分或视频资料 | 无法形成修改后的返回档案，不确认修改成功 | 系统异常，请稍后重试 | 本次基础资料修改不生效。 |
| 非空头像或视频资源无法由七牛云形成访问地址，或视频资源标识无法形成封面地址 | 无法交付修改后的个人档案，不确认修改成功 | 系统异常，请稍后重试 | 本次基础资料修改不生效。 |
| 启用的整数或浮点配置无法解析 | 将该配置按 `0` 使用，继续形成修改后的个人档案 | 修改成功 | 基础资料按本次提交生效，返回的等级、评分或限制可能采用 `0`。 |
| 修改内容超过数据库字段可保存范围，基础资料保存失败 | 终止修改 | 系统异常，请稍后重试 | 本次基础资料修改不生效。 |
| 基础资料、网球档案、关注关系、约球、配置读取或保存失败，或发生其他未归类错误 | 终止修改 | 系统异常，请稍后重试 | 本次基础资料修改不生效。 |

## 业务边界

- 本服务只允许当前登录用户修改本人资料，不接受指定其他用户。
- 本服务只修改昵称、头像、性别、生日、当前城市和个人简介，不修改用户编号、手机号、邮箱、NTRP、评分、档案状态或展示视频。
- 本服务按字段执行部分修改：未提交和显式提交 `null` 的效果相同，均保留原值；字符串字段提交空字符串则会清空原内容。
- 本服务不建立账户或网球档案；没有网球档案或档案待完善也不妨碍基础资料修改。
- 本服务只保存头像资源标识，不负责上传、裁剪或删除头像文件，也不验证资源是否存在或属于本人。
- 本服务不校验城市是否开放或是否存在，只在形成返回档案时查找城市名称。
- 本服务成功后交付与“我的档案查询”相同范围的聚合结果，但不负责维护其中的关注关系、约球统计、NTRP、评分和视频。
- 本服务不会改变个人档案的 `NONE`、`TBC`、`NORMAL` 或 `UNDER_REVIEW` 状态。
