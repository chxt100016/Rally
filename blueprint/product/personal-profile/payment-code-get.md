## 一句话价值

向用户交付本人当前保存的收款码资料。

## 核心概念

- 收款码  约球发布者提供的线下费用收取图片，不代表平台已完成收款或记账。

## 业务对象

### 收款码

| 业务名称 | 描述 | 取值说明 |
|---|---|---|
| 所属用户 | 标识收款码归属的当前用户。 | — |
| 图片资源标识 | 标识当前保存的收款码图片。 | — |
| 图片访问地址 | 收款码图片的限时访问地址；资源标识为空白时不交付。 | — |

## 交付内容

类型: 查询类

向消费者交付当前业务事实的查询结果；身份与状态造成的展示差异，以及列表的排序、分页和无结果口径，以本节下列规则及主流程、分支与异常为准。

## 主流程

触发源：接口（用户）；终态：交付本人当前收款码的资源标识和七牛云一小时有效访问地址，不改变任何业务对象状态。

1. 依据当前登录身份确定要查询的用户。
2. 读取本人资料类型为 `wechat_payment_code` 的唯一用户扩展资料。
3. 交付其中保存的收款码图片资源标识。
4. 依据该资源标识由七牛云签发一小时有效的图片访问地址，并与资源标识一并交付。

## 分支与异常

| 什么情况 | 怎么处理 | 对外提示 | 做了一半的怎么收场 |
|---|---|---|---|
| 未携带登录凭据，或登录凭据未使用约定格式 | 不受理查询 | 登录已过期，请重新登录 | 本服务只读，没有业务对象需要恢复 |
| 登录凭据已过期、签名错误或内容无法验证 | 不受理查询 | 登录凭证无效，请重新登录 | 本服务只读，没有业务对象需要恢复 |
| 本人在 `user_ext` 中没有 `ext_key` 为 `wechat_payment_code` 的资料 | 成功交付空结果，不自动建立收款码资料 | 查询成功 | 本服务只读，没有业务对象需要恢复 |
| 收款码资料存在，但 `ext_value` 为 `null`、空字符串或仅含空白字符 | 交付已有查询结果；`key` 保留原值，`paymentCodeUrl` 为空 | 查询成功 | 本服务只读，没有业务对象需要恢复 |
| 同一用户存在多条 `ext_key` 为 `wechat_payment_code` 的资料 | 无法确定唯一的当前收款码，终止查询 | 系统异常，请稍后重试 | 本服务只读，没有业务对象需要恢复 |
| 七牛云配置不可用，或无法签发图片访问地址 | 终止查询，不交付不完整结果 | 系统异常，请稍后重试 | 本服务只读，没有业务对象需要恢复 |
| `user_ext` 读取失败，或发生其他未归类错误 | 终止查询 | 系统异常，请稍后重试 | 本服务只读，没有业务对象需要恢复 |

## 业务边界

- 本服务从当前登录用户查询本人收款码开始，到交付当次查询结果为止，全程不修改业务对象状态。
- 本服务只查询当前登录用户本人，不接受指定其他用户；约球详情向参与者展示发布者收款码不属于本服务。
- 本服务没有收款码资料时交付空结果，不建立默认资料；收款码保存属于独立业务服务。
- 本服务只交付已有收款码，不上传图片、不签发上传凭证，也不修改或删除收款码资料及图片。
- 本服务将已保存内容直接作为七牛云资源标识签发访问地址，不核验图片是否存在、是否属于本人、是否确为收款码。
- 本服务交付的七牛云访问地址仅在签发后的一小时内有效，不承诺到期后仍可访问。
- 本服务不向约球参与者付款、不确认费用到账，也不形成平台收付款记录。
- 本服务以登录凭据中的用户标识查询资料，不另行确认对应账户或个人档案仍然存在。

## 遗留与待定

| 等级 | 待定的是什么 | 要谁来定 |
|---|---|---|
| P2 | `user_ext.ext_key` 写死为历史值 `wechat_payment_code`，但业务定义并未限定微信收款码；需产品确认允许展示的收款码渠道范围，技术负责人确认历史数据兼容口径。 | 产品与用户运营负责人 |
| P1 | `user_ext.ext_value` 的建表说明允许保存付款码 URL 或 base64，当前查询却将其作为七牛云资源标识签发访问地址；需产品和技术负责人统一存量及新增数据格式。 | 产品与用户运营负责人 |
| P1 | 七牛云访问地址有效期写死为 3600 秒且没有业务说明或配置；需产品确定有效期，并由技术负责人确定配置方式。 | 产品与用户运营负责人 |
| P1 | 没有收款码资料时当前成功交付空结果，没有明确的“未保存”状态或提示；需产品确定消费者应如何识别和展示该情况。 | 产品与用户运营负责人 |
| P2 | 当前不核验七牛云资源是否存在、是否属于本人、格式是否为图片以及内容是否为收款码；需产品确定查询前的资源有效性要求。 | 产品与用户运营负责人 |
| P2 | 有效登录凭据中的用户标识即使已找不到对应账户或个人档案，当前仍会按“没有收款码资料”成功返回空结果；需产品确定是否应改为身份失效。 | 产品与用户运营负责人 |
