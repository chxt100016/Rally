## 一句话价值

为内容人员将一批网球业务原文直接交付为对应译文。

## 核心概念

- 翻译条目  某类业务文本、原文和目标语言组成的一项待译或已译内容。
- 即时翻译  翻译调用方当次提交的临时文本并直接返回译文，不登记或保存翻译条目。

## 业务对象

### 即时翻译

| 业务名称 | 描述 | 取值说明 |
|---|---|---|
| 原文 | 需要翻译的一条或多条网球业务文本。 | — |
| 业务语境 | 指明原文所属对象，帮助译文采用对应的网球表达。 | 球场；球员：优先采用职业巡回赛官方中文译名；职业赛事：优先采用官方中文名称并避免重复赛事类型；场地类型；城市。 |
| 目标语言 | 希望取得译文的语言。 | 简体中文、繁体中文、英语、日语或韩语。 |
| 译文 | 与输入原文数量相同、顺序一一对应的翻译结果。 | — |

## 交付内容

类型: 执行类

消费者当场取得主流程所述的外部处理效果与成功结果；重复发起、下游失败和已完成结果的处理，以本节下列规则及分支与异常为准。

## 主流程

触发源：内容人员发起 HTTP 请求；终态：直接取得与输入顺序一一对应的译文列表。

1. 接收一批原文，并取得每条原文所属的业务对象类型和目标语言。
2. 按业务对象类型补充网球领域语境和专有名词译法要求。
3. DeepSeek 按原始顺序逐条翻译，并且只交付译文本身。
4. 确认译文数量与原文数量一致后，按原顺序向内容人员交付译文列表。

## 分支与异常

| 什么情况 | 怎么处理 | 对外提示 | 做了一半的怎么收场 |
|---|---|---|---|
| 输入列表为空 | 不发起翻译，直接交付空列表 | 翻译成功，无额外提示 | 没有需要收场的业务数据 |
| 业务对象类型或目标语言不是支持的取值 | 请求无法进入翻译 | 未定义统一业务提示 | 不产生译文，也不保存任何内容 |
| 任一条输入缺少业务对象类型或目标语言，或条目本身为空 | 本次翻译异常终止 | 未定义统一业务提示 | 不保存任何内容，也不交付部分译文 |
| 任一条输入缺少原文 | 仍把字面文本 `null` 作为原文交给 DeepSeek | 翻译成功时照常返回对应结果，无输入缺失提示 | 不保存任何内容 |
| DeepSeek 未返回有效结果或翻译调用失败 | 不交付译文列表 | 当前以无译文结果表示，未提供业务错误原因 | 不保存任何内容，调用方需自行决定是否重试 |
| DeepSeek 返回的译文数量与原文数量不一致 | 丢弃整批结果 | 当前以无译文结果表示，未指出数量差异 | 不交付部分译文，也不保存任何内容 |
| DeepSeek 返回空白译文但总行数一致 | 连同其他译文按原顺序交付 | 翻译成功，无质量提示 | 空白译文不会被补译或保存 |

## 业务边界

本服务负责把调用方当次提交的一批网球业务文本交给 DeepSeek 翻译，并直接交付按输入顺序对应的译文。它不查询、建立或更新持久化翻译条目，不保存即时译文，不审核译文质量，也不承担“待译内容批处理”的存量扫描、分批处理和成功条数统计。

## 遗留与待定

| 等级 | 待定的是什么 | 要谁来定 |
|---|---|---|
| P2 | 即时翻译没有条数、单条长度或整批总量上限，所有输入一次交给 DeepSeek；可接受的批量范围和超限处理需由内容负责人确定。 | 产品与内容运营负责人 |
| P2 | 输入允许在同一批中混合业务对象类型和目标语言；是否应按语言或类型拆批，以及混合批次的验收规则待翻译负责人确定。 | 产品与内容运营负责人 |
| P2 | 当前列出的五种目标语言来自写死取值，没有按业务场景配置开放范围；各语言是否正式可用、是否需要默认语言及不支持语言的替代策略待产品负责人确定。 | 产品与内容运营负责人 |
| P2 | DeepSeek 使用的模型写死为 `deepseek-v4-pro`，且没有备用翻译来源；模型选型、不可用时的降级方式和费用控制责任人待定。 | 产品与内容运营负责人 |
| P2 | DeepSeek 必须按输入顺序逐行返回且数量完全一致，结果不携带原文标识；错序但数量一致时无法发现，对应关系和验收机制待翻译负责人确定。 | 产品与内容运营负责人 |
| P1 | 外部翻译失败、空结果和译文数量不一致都以无译文结果表示，没有业务错误码、失败原因或部分成功交付；对外失败语义和重试责任待产品负责人确定。 | 产品与内容运营负责人 |
| P2 | 输入结构还允许携带条目标识和已有译文，但即时翻译不会使用它们；是否应从即时输入中移除这些无效信息待产品与接口负责人确定。 | 产品与内容运营负责人 |
| P2 | 原文中的换行会与逐行对应规则产生歧义，返回的空白译文也会被直接交付；文本格式限制和最低质量标准待翻译负责人确定。 | 产品与内容运营负责人 |
| P1 | 原文缺失时会被当作字面空值内容继续翻译，业务对象类型或目标语言缺失时则异常终止；输入必填校验和缺失提示待产品负责人确定。 | 产品与内容运营负责人 |
| P2 | 除球员和职业赛事外，球场、场地类型和城市没有额外译法规则；术语表、官方译名来源和人工校对机制待内容负责人确定。 | 产品与内容运营负责人 |
| P1 | 入口未体现内容人员身份或权限校验；谁可以调用即时翻译及如何限制外部翻译成本待产品与安全负责人确定。 | 产品与内容运营负责人 |
