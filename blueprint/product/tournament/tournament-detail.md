## 一句话价值

向用户交付赛事、报名、对阵、当前动作与线下安排。

## 核心概念

- 自办赛事  由业务方配置规则、接受报名、组织匹配并推进比赛的竞赛活动。
- NTRP  用于描述网球水平的等级值，既用于个人展示，也用于约球和赛事准入。
- 赛事报名  用户参加自办赛事的资格与进度载体，记录参赛编号、阶段、轮次、状态和偏好。
- 参赛编号  一支参赛单元的编号；单打通常对应一人，双打队友共享同一编号。
- 资格赛  自办赛事进入正赛前的筛选阶段，胜者可能先进入待支付。
- 正赛  自办赛事锁定席位后的淘汰阶段，胜者按轮次继续晋级。
- 匹配池  当前轮次中处于等待匹配、可被编入新比赛的参赛单元集合。
- 赛事比赛  自办赛事中一次由若干参赛单元完成的对阵，经历匹配、订场、确认、比赛和赛果确认。
- 订场人  一场赛事比赛中负责提交比赛时间和场地安排的参赛者。
- 赛约  为一场赛事比赛建立的时间与场地安排，以专属约球承载；全员确认前可重订或拒绝。
- 赛果  赛事比赛提交的胜方结论，需要其他参赛者确认或由超时规则完成确认。
- 当前动作  依据赛事时间、本人报名和当前比赛共同推导的下一步提示，不是单独保存的业务状态。
- 报名可用选项  用户报名或修改报名偏好时，可选择的活动区域与可比赛时间。

## 交付内容

类型: 查询类

向消费者交付当前业务事实的查询结果；身份与状态造成的展示差异，以及列表的排序、分页和无结果口径，以本节下列规则及主流程、分支与异常为准。

无。查询不会改变赛事、报名或比赛的状态；已存在赛事报名的登录用户会更新 `rally_tournament_entry.last_visit_time`，但报名状态保持不变。

## 主流程

触发源：接口（用户或匿名访问者）；终态：交付赛事详情聚合视图，已报名用户的最近访问时间更新为本次查询时间。

1. 依据赛事编号取得自办赛事、全部赛事报名和全部赛事比赛，形成赛事基础资料、时间展示状态与公开进程，并按赛事举办城市交付完整区县级行政区划和固定的可比赛时间选项。
2. 汇总各轮比赛和参与者，交付赛事签表、参赛者名录、按轮次参赛者概览及累计拒赛统计。
3. 匿名访问者获得公开区块和未登录动作提示，查询到此不形成本人报名、比赛、时间线或评论状态。
4. 已登录但未报名的用户获得当前报名动作；报名仍开放时，同时获得档案、性别、NTRP 与手机号限制。
5. 已有报名的用户将本次访问记为最近访问，获得本人报名、个人赛事时间线和结合赛事进度形成的当前动作；冠军显示 `CHAMPION`，等待报名轮次晚于赛事当前轮次时显示 `ADVANCED`，只有进入赛事当前轮匹配池时才显示 `WAITING_MATCH`。
6. 本人报名处于比赛中时，取得尚未完成或终止的当前比赛，交付参赛者、确认进度、对手最近访问时间，以及符合身份条件的对手手机号；订场阶段另交付对手报名偏好。
7. 当前比赛已有赛约时交付赛约活动卡片；已进入待提交赛果但尚未晚于开赛时间时，当前动作改为待开赛。
8. 赛事已建立线下赛活动时，交付该活动的约球卡片。
9. 为赛事、用户和参赛者图片生成七牛云限时访问地址，并补充昵称、性别、NTRP、当前动作标题和说明。
10. 对尚未退赛的已报名用户交付赛事评论未读数，但不改变评论阅读位置。

## 分支与异常

| 什么情况 | 怎么处理 | 对外提示 | 做了一半的怎么收场 |
|---|---|---|---|
| 指定赛事不存在 | 终止查询 | 赛事不存在 | 没有业务对象被改变 |
| 赛事城市无法在行政区划名录中识别 | 报名可用区域交付空列表，可比赛时间仍正常交付 | 查询成功 | 不使用杭州或其他城市的区域代替，不修改赛事资料 |
| 未登录 | 交付公开区块及 `NOT_LOGGED_IN` 当前动作 | 查询成功 | 不记录最近访问，不交付本人区块 |
| 已登录但没有赛事报名 | 根据报名截止时间和当前轮次交付 `NOT_REGISTERED` 或 `NOT_REGISTERED_CLOSED` | 查询成功 | 不建立报名，不记录最近访问 |
| 未报名且当前动作为 `NOT_REGISTERED` | 依据本人资料交付可叠加的报名限制；没有限制时交付空列表 | 查询成功 | 不建立或修改资料与报名 |
| 本人报名为 `FROZEN` | 当前动作交付 `FROZEN`，限制只检查登录身份和手机号 | 查询成功 | 报名保持冻结 |
| 本人报名为 `WAITING`，且本人当前轮次晚于赛事当前轮次 | 当前动作交付 `ADVANCED`（已晋级） | 查询成功 | 报名保持等待下一轮，不会被当前轮匹配 |
| 本人报名为 `CHAMPION` | 当前动作交付 `CHAMPION`，即使赛事已结束也优先显示冠军文案 | 查询成功 | 冠军报名和赛事终态不变 |
| 本人报名为 `WITHDRAWN` | 交付本人报名和时间线，不交付评论未读数；赛事未结束时动作为 `WITHDRAWN`，已结束时动作为 `END` | 查询成功 | 报名保持已退赛 |
| 本人报名为 `IN_MATCH`，但没有找到尚未完成或终止的比赛 | 不交付当前比赛，当前动作按 `WAITING_MATCH` 交付 | 查询成功 | 报名仍保持 `IN_MATCH` |
| 当前比赛没有关联赛约 | 不交付赛约卡片；待提交赛果动作不会再按开赛时间细分 | 查询成功 | 比赛和报名不变 |
| 当前比赛或线下赛活动记录了约球编号，但对应 `rally_meetup` 不存在 | 终止详情聚合 | 约球活动不存在 | 若本人已有报名，最近访问时间可能已更新，不自动恢复 |
| 关联约球记录了球场编号，但对应 `rally_court` 不存在 | 使用室外硬地和约球开始时段形成卡片背景 | 查询成功 | 不补建或修改球场 |
| 参赛用户资料不存在 | 该用户的昵称、头像、性别、NTRP 或手机号留空，其他赛事内容继续交付 | 查询成功 | 不补建用户或个人档案 |
| 未报名或冻结的当前用户资料不存在 | 无法完成限制判断，终止查询 | 登录凭证无效，请重新登录 | 没有报名可修改；冻结用户的最近访问时间已先更新且不自动恢复 |
| 当前用户无法在当前比赛中以本人参赛编号唯一定位，或同一用户同时落在不同参赛编号 | 不交付任何对手手机号 | 查询成功 | 其他当前比赛内容正常交付 |
| 对手未绑定手机号 | 该对手手机号留空 | 查询成功 | 其他当前比赛内容正常交付 |
| 当前比赛处于待提交赛果，但关联约球开始时间为空 | 保持待提交赛果动作 | 查询成功 | 比赛和赛约不变 |
| 重订原因是无法识别的非空值 | 在当前动作说明中原样展示该值 | 查询成功 | 不修改重订记录 |
| 奖金内容无法转换为整数列表，赛事主题、报名偏好或其他存储内容无法识别 | 终止详情聚合 | 系统异常，请稍后重试 | 若本人已有报名，最近访问时间可能已更新，不自动恢复 |
| 赛事、报名、比赛或参与者的枚举值无法识别 | 终止详情聚合 | 系统异常，请稍后重试 | 若本人已有报名，最近访问时间可能已更新，不自动恢复 |
| 七牛云无法签发赛事图片或用户头像访问地址 | 终止详情聚合 | 系统异常，请稍后重试 | 若本人已有报名，最近访问时间可能已更新，不自动恢复 |
| 赛事、报名、比赛、用户、评论、约球或球场资料读取失败 | 终止查询 | 系统异常，请稍后重试 | 若本人已有报名，最近访问时间可能已更新，不自动恢复 |

## 业务边界

- 本服务负责从指定赛事编号形成当次赛事聚合视图；不创建、修改、激活或废弃赛事，不推进赛事轮次。
- 本服务允许匿名访问，也不按 `DRAFT`、`ACTIVE`、`FINISHED` 或 `ABANDONED` 限制赛事可见性；只要赛事记录存在就会交付详情。
- 本服务不建立、修改、冻结、解冻或撤销赛事报名；已有报名用户查询时只更新 `last_visit_time`。
- 本服务不执行比赛匹配、认领订场、提交或确认赛约、提交或确认赛果，也不改变赛事比赛或参与者确认状态。
- 本服务交付当前动作和报名限制，但不保证动作本身能够绕过对应业务服务的再次校验。
- 本服务交付报名与修改偏好所需的区域和时间选项；区域来自赛事城市的完整行政区划名录，只作选择展示，不在本服务中校验或修改报名偏好。
- 本服务交付赛事评论未读数但不交付评论内容，也不推进已读位置；评论发布和拉取由赛事讨论服务负责。
- 本服务只将关联赛约和线下赛活动压缩成约球卡片，不交付完整约球详情，也不修改约球或球场。
- 本服务只在能够唯一确认本人参赛编号时交付不同参赛编号对手的已绑定手机号，不交付本人或同队成员手机号。
- 本服务把赛事图片、用户头像转换为一小时有效的七牛云访问地址，不负责上传、替换或删除图片。
