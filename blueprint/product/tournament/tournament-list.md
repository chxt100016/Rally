## 一句话价值

向运营分页交付赛事状态与配置摘要。

## 核心概念

- NTRP  用于描述网球水平的等级值，既用于个人展示，也用于约球和赛事准入。
- 自办赛事  由业务方配置规则、接受报名、组织匹配并推进比赛的竞赛活动。

## 业务对象

### 赛事名录

| 业务名称 | 描述 | 取值说明 |
|---|---|---|
| 赛事列表 | 本页符合筛选条件的赛事摘要；没有结果时为空。 | — |
| 赛事编号 | 每项赛事的唯一业务编号。 | — |
| 赛事名称 | 赛事对外展示名称。 | — |
| 赛事图片 | 包含活动海报和微信群二维码的访问地址。 | — |
| 页面主题 | 包含主操作按钮颜色和页面背景色。 | — |
| 城市 | 赛事举办城市。 | — |
| NTRP 等级 | 赛事要求的参赛水平等级。 | — |
| 性别限制 | 赛事对报名者性别的要求。 | 不限性别：男性和女性均可；仅限男性：只有男性可报名；仅限女性：只有女性可报名。 |
| 正赛签位 | 正赛可容纳的参赛席位数。 | — |
| 线下承接轮次 | 从该轮开始由统一线下活动承接。 | 资格赛、64 强、32 强、16 强、8 强、半决赛、决赛。 |
| 资格赛分组人数 | 资格赛每场包含的参赛单元数量。 | — |
| 报名费 | 参赛者锁定正赛席位所需费用，单位为分。 | — |
| 赛事时间 | 包含报名与资格赛的开始、截止时间。 | — |
| 拒赛次数上限 | 资格赛和正赛允许累计的拒赛次数。 | — |
| 赛事状态 | 赛事当前管理阶段。 | 草稿：尚未激活；已激活：正在运营；已废弃：赛事已终止。 |
| 已锁定席位 | 已经支付报名费并锁定的正赛席位数。 | — |
| 赛事总数 | 符合全部筛选条件的赛事数量。 | — |
| 是否还有下一页 | 表示当前页之后是否仍有赛事。 | — |

## 状态机

无。本服务只读取赛事名录，不改变赛事、报名或比赛状态。

## 主流程

触发源：HTTP（运营）；终态：按创建时间倒序交付一页赛事配置与状态摘要。

1. 确认发起者具备运营访问资格，并接收可选筛选条件与分页要求。
2. 按提供的城市编码、赛事状态和 NTRP 等级共同筛选自办赛事；未提供的条件不限制结果。
3. 将符合条件的赛事按创建时间从新到旧排列，取得指定页并计算符合条件的总数和是否还有下一页。
4. 为每项赛事交付编号、名称、城市、参赛限制、签位、线下轮次、资格赛分组、费用、时间、拒赛规则、状态、已锁定席位、创建时间和主题摘要。
5. 对已保存的海报与微信群二维码图片标识生成七牛云临时访问地址；没有图片标识时对应地址为空。
6. 交付赛事摘要列表、符合条件的赛事总数和是否还有下一页；没有匹配赛事时交付空列表。

## 分支与异常

| 什么情况 | 怎么处理 | 对外提示 | 做了一半的怎么收场 |
|---|---|---|---|
| 运营访问凭据未配置、未提供或不匹配 | 拒绝查询 | 无权限访问 | 不交付赛事名录。 |
| 未提供页码，或页码小于 1 | 拒绝查询 | `pageNum: 请填写页码` 或 `pageNum: 页码最小为1` | 不交付赛事名录。 |
| 未提供每页条数，或每页条数不在 1 至 100 | 拒绝查询 | 返回 `pageSize` 对应的必填、最小值或最大值提示 | 不交付赛事名录。 |
| 提交的赛事状态无法识别 | 拒绝查询 | 系统异常，请稍后重试 | 不交付赛事名录。 |
| 筛选条件没有匹配赛事，或页码超过结果范围 | 正常交付空列表 | 无 | 同时交付实际总数，`hasMore` 为否。 |
| 已保存的赛事枚举或主题内容无法识别 | 查询失败 | 系统异常，请稍后重试 | 不交付部分名录。 |
| 七牛云临时访问地址生成失败 | 查询失败 | 系统异常，请稍后重试 | 不交付部分名录。 |

## 业务边界

- 本服务负责按城市、赛事状态和 NTRP 等级筛选，并分页交付运营所需的赛事配置与状态摘要。
- 本服务不按赛事名称、比赛类型、报名时间或当前轮次筛选，也不交付赛事规则、奖金、报名、对阵、赛果和线下赛活动详情。
- 本服务不创建、修改、激活或废弃赛事，不推进报名、匹配、比赛、支付或线下承接。
- 本服务交付的是查询当时的当前页结果，不承诺相邻两次分页查询期间赛事数据保持不变。

## 遗留与待定

- 城市编码和 NTRP 等级均按保存值精确筛选，没有格式校验或名录校验；运营端允许输入的范围应由赛事产品确认。
- 列表没有赛事名称搜索、比赛类型、报名时间或当前轮次等筛选条件；运营实际所需的检索维度应由赛事运营负责人确认。
- 名录只按 `create_time` 倒序排列；创建时间相同的赛事没有第二排序条件，跨页结果顺序是否需要稳定规则应由赛事产品确认。
- 页码超过结果范围时仍返回实际总数和空列表；是否需要提示页码超界应由赛事产品确认。
- 海报与微信群二维码访问地址由七牛云生成，当前有效期为一小时；运营页面对地址有效期的预期应由赛事产品确认。
