## 一句话价值

按职业赛事交付种子与后续赛程分组

## 核心概念

- 职业赛事  从公开数据源采集的 ATP/WTA 赛事，用于赛程、比分和内容展示，不接受本产品用户报名。
- 赛程  职业比赛的日期、时间、场地和对阵安排；与签表结构不是同一份数据。
- 签表  职业赛事的参赛位置、轮次结构和潜在晋级路径。
- 种子  职业赛事中用于体现重点球员及签表排序的编号。
- 待赛比赛  有比赛日期且状态不是 `FINISHED` 的职业比赛；查询结果还会带上与其同比赛日期的已结束比赛。

## 交付内容

类型: 查询类

向消费者交付当前业务事实的查询结果；身份与状态造成的展示差异，以及列表的排序、分页和无结果口径，以本节下列规则及主流程、分支与异常为准。

## 主流程

触发源：HTTP（用户或匿名访问者）；终态：所选职业赛事的种子分组与后续赛程分组已交付。

1. 接收一组外部赛事编号，汇总这些赛事下所有签表的非零种子资料。
2. 依据所选赛事中全部已结束比赛识别落败种子，并把种子归入 ATP、WTA 或已淘汰分组；各组内按种子号升序排列。
3. 取得有比赛日期且尚未结束的比赛，再补入与这些比赛同比赛日期的已结束比赛；双方球员都未确定的场次不交付。
4. 为每场比赛补充双方球员的展示名、国家或地区、种子号，并形成轮次、排期、状态、逐盘比分、胜方及比赛时长的展示资料。
5. 先按比赛日期形成日期组，再在每个日期下按球场形成球场组；同一球场内有胜方的比赛排在前面，其余按计划开赛时间升序排列。
6. 日期组按日期升序排列；原始球场名符合“Court 加数字”时按该数字排序，其余球场按场内最小种子号排序。
7. 将已有的简体中文球场名和球员名用于分组、比赛及种子展示；没有译文时保留原文并登记待译条目。
8. 一次性交付种子分组和日期、球场两级赛程分组。

## 分支与异常

| 什么情况 | 怎么处理 | 对外提示 | 做了一半的怎么收场 |
|---|---|---|---|
| 未提供必填的赛事编号参数 | 拒绝本次查询 | 系统异常，请稍后重试 | 未产生变更 |
| 赛事编号列表为空或没有匹配资料 | 交付空的种子分组和比赛分组 | 查询成功，无错误提示 | 不改变职业赛事数据；不登记翻译条目 |
| 提供的赛事编号没有对应比赛、签表或种子资料 | 对缺少的部分交付空列表 | 查询成功，无错误提示 | 已找到的其他赛事资料照常交付 |
| 一场比赛的双方球员编号都为空 | 不交付该场比赛 | 无 | 其他比赛照常交付 |
| 有球员编号但没有对应球员资料 | 仍交付该球员编号，并以编号作为比赛中的展示名 | 无 | 该比赛及其他资料照常交付；种子条目的展示名和国家或地区可能为空 |
| 国家或地区代码不在已知清单 | 原代码同时作为国家或地区名称交付，不提供旗帜代码 | 无 | 其他球员资料照常交付 |
| 比赛状态不是已知枚举值 | 原状态仍交付，不提供状态中文名称；排期按已有排期类型展示 | 无 | 该比赛及其他资料照常交付 |
| 排期类型为空或固定、不早于类型缺少计划时间 | 不提供排期展示文案 | 无 | 该比赛及其他资料照常交付 |
| 排期类型不在已知枚举值 | 排期展示为“待定” | 无 | 该比赛及其他资料照常交付 |
| 球场名或球员名没有简体中文译文 | 保留原文并登记待译条目 | 无 | 本次查询结果仍正常交付 |
| 查询或组装资料失败 | 本次查询失败 | 系统异常，请稍后重试 | 已登记的待译条目是否保留取决于失败发生时点，未见统一撤销规则 |

## 业务边界

- 负责按外部赛事编号查询种子资料，以及有日期的非完赛比赛和同日已结束比赛。
- 负责把种子划分为 ATP、WTA、已淘汰三组，把比赛组织为日期、球场两级分组。
- 负责交付球员、国家或地区、种子、轮次、排期、状态、比分、胜方和时长等比赛展示资料。
- 负责使用已有简体中文球场名与球员名，并为缺少的译文登记待译条目。
- 不负责采集或修改赛事、签表、球员、种子、比赛与比分数据。
- 不负责生成译文；新登记的待译条目需由“待译内容批处理”继续处理。
- 不负责只查询纯粹的已结束比赛；该承诺属于“完赛比赛查询”。

|---|---|---|

| P1 | 种子查询会合并所选赛事下所有签表，不按 `year`、`draw_type` 或参赛资料状态筛选；单打、双打、退出和退赛资料是否都应进入结果需产品确认。 | 产品与职业赛事数据负责人 |
| P2 | 尚未淘汰但所属赛事 `tour` 不是 `ATP` 的种子都会归入 `WTA`，包括空值或其他巡回赛类型；分组规则需赛事数据负责人确认。 | 产品与职业赛事数据负责人 |
| P1 | 种子淘汰状态只要发现球员在任一已结束比赛中落败即判定，未核对该比赛所属签表；跨项目或跨年份比赛是否会误判需赛事数据负责人确认。 | 产品与职业赛事数据负责人 |
| P2 | “待赛”结果会混入与待赛比赛同日期的已结束比赛，是否符合待赛查询的产品预期需产品确认。 | 产品与职业赛事数据负责人 |
| P2 | 日期展示以今天和数据中最早日期的较早者为锚点；存在过去未结束比赛时，最早的过去日期会显示为“今天”，该展示规则需产品确认。 | 产品与职业赛事数据负责人 |
