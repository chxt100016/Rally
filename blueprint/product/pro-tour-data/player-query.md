## 一句话价值

按巡回赛交付球员排名、积分与资料

## 核心概念

- 职业赛事  从公开数据源采集的 ATP/WTA 赛事，用于赛程、比分和内容展示，不接受本产品用户报名。
- 职业球员  从公开数据源采集、归属于某一职业巡回赛的球员资料；同一外部球员编号需结合巡回赛识别。
- 翻译条目  某类业务文本、原文和目标语言组成的一项待译或已译内容。

## 业务对象

### 职业球员

| 业务名称 | 描述 | 取值说明 |
|---|---|---|
| 球员编号 | 与所属巡回赛共同唯一识别一名职业球员。 | — |
| 所属巡回赛 | 球员参加的职业巡回赛。 | ATP：男子职业巡回赛；WTA：女子职业巡回赛。 |
| 球员姓名 | 由名和姓组成，优先展示简体中文译名。 | — |
| 国家或地区 | 包含三位代码、中文名称和旗帜代码。 | — |
| 当前排名 | 球员当前的职业排名；未排名球员不进入结果。 | — |
| 排名积分 | 球员当前的排名积分。 | — |
| 出生日期 | 球员出生日期。 | — |
| 年龄 | 根据出生日期和查询当日计算的周岁。 | — |

## 交付内容

类型: 查询类

向消费者交付当前业务事实的查询结果；身份与状态造成的展示差异，以及列表的排序、分页和无结果口径，以本节下列规则及主流程、分支与异常为准。

## 主流程

触发源：HTTP（用户或匿名访问者）；终态：所选巡回赛的已排名球员资料已按排名交付。

1. 接收职业巡回赛条件，并将其统一为大写。
2. 取得该巡回赛中已有排名的职业球员，按当前排名升序排列。
3. 将球员名与姓组合成完整姓名，并依据国家或地区代码形成中文名称和旗帜代码。
4. 有出生日期时，以查询当日计算周岁，并按 `yyyy-MM-dd` 交付出生日期。
5. 球员姓名有简体中文译文时交付译文；没有可用译文时保留原文，并在尚无条目时登记待译内容。
6. 交付球员编号、排名、姓名、国家或地区、积分、年龄和出生日期清单。

## 分支与异常

| 什么情况 | 怎么处理 | 对外提示 | 做了一半的怎么收场 |
|---|---|---|---|
| 未提供必填的巡回赛条件 | 拒绝本次查询 | 系统异常，请稍后重试 | 未改变球员资料 |
| 巡回赛条件为空白 | 交付空清单 | 查询成功 | 不读取或改变球员资料，也不登记翻译条目 |
| 巡回赛不存在或没有已排名球员 | 交付空清单 | 查询成功 | 不改变球员资料，也不登记翻译条目 |
| 球员没有出生日期 | 不交付年龄和出生日期 | 查询成功 | 该球员的其他资料照常交付 |
| 国家或地区代码为空 | 不交付国家或地区资料 | 查询成功 | 该球员的其他资料照常交付 |
| 国家或地区代码不在已知清单 | 原代码同时作为国家或地区名称交付，不提供旗帜代码 | 查询成功 | 该球员及其他资料照常交付 |
| 球员姓名没有可用的简体中文译文 | 保留原文；尚无翻译条目时登记待译内容 | 查询成功 | 球员仍正常交付；待译条目留待后续翻译 |
| 待译内容因重复或其他原因未能登记 | 保留原文并继续交付球员 | 查询成功 | 已登记的其他待译条目保留 |
| 球员资料或翻译资料读取失败 | 终止本次查询 | 系统异常，请稍后重试 | 球员资料不变；异常前已登记的待译条目保留 |

## 业务边界

- 负责按职业巡回赛交付已有排名的球员清单，并按排名升序排列。
- 负责交付球员编号、排名、积分、完整姓名、国家或地区、年龄和出生日期。
- 负责使用已有的简体中文球员姓名，并为尚无记录的姓名登记待译条目。
- 不负责采集或修改职业球员及排名资料，也不负责生成译文。
- 不负责交付未排名球员、球员头像、持拍手、性别、参赛签表、比赛经历或晋级路径。

| 等级 | 待定的是什么 | 要谁来定 |
|---|---|---|
| P2 | 查询条件没有限制为 `ATP` 或 `WTA`，任意非空值都会转为大写后查询；有效巡回赛范围及非法值的对外处理需职业赛事数据负责人确认。 | 产品与职业赛事数据负责人 |
| P2 | 查询不分页且没有数量上限；完整巡回赛球员清单的交付规模需产品与数据负责人确认。 | 产品与职业赛事数据负责人 |
| P2 | 当前只交付已有排名的球员，未排名球员被直接排除；这是否符合“职业球员查询”的完整范围需产品负责人确认。 | 产品与职业赛事数据负责人 |
| P2 | 球员姓名固定按“名、空格、姓”拼接，与其他职业赛事查询中优先只展示姓的规则不同；统一展示口径需内容负责人确认。 | 产品与职业赛事数据负责人 |
| P1 | 年龄以查询当日和出生日期直接计算，未校验未来出生日期；异常日期的处理规则需职业赛事数据负责人确认。 | 产品与职业赛事数据负责人 |
| P2 | `tour_player` 允许 `player_id` 为空，但它又作为查询项中的球员标识；缺少外部球员编号时能否交付需数据负责人确认。 | 产品与职业赛事数据负责人 |
| P2 | 查询项不交付所属 `tour`，且没有头像字段或头像来源；跨巡回赛识别方式及是否需要球员头像需产品负责人确认。 | 产品与职业赛事数据负责人 |
| P1 | 空的 `translated_text` 会被视为没有可用译文并保留原文，但不会重新登记；待译状态、人工审核与译文生效时点需内容负责人确认。 | 产品与职业赛事数据负责人 |
