## 一句话价值

为运营更新 ATP 与 WTA 球员排名和积分资料

## 核心概念

- 职业赛事  从公开数据源采集的 ATP/WTA 赛事，用于赛程、比分和内容展示，不接受本产品用户报名。
- 职业球员排名  ATP 或 WTA 发布的球员当前名次与积分快照。

## 业务对象

### 职业球员排名

| 业务名称 | 描述 | 取值说明 |
|---|---|---|
| 球员编号 | 与所属巡回赛共同唯一识别一名职业球员；缺少编号的来源记录不保存。 | — |
| 所属巡回赛 | 本次排名所属的职业巡回赛。 | ATP：男子职业巡回赛；WTA：女子职业巡回赛。 |
| 球员姓名 | 球员的名和姓。 | — |
| 国家或地区 | 球员所属国家或地区的三位代码。 | — |
| 出生日期 | 球员出生日期；来源日期无法识别时不刷新。 | — |
| 当前排名 | 本次采集的排名顺位，当前范围为第一至第二百名。 | — |
| 排名积分 | 球员当前的排名积分。 | — |

## 状态机

无。职业球员没有由本服务控制的业务状态；排名与积分作为最新来源快照覆盖，球员身份保持不变。

## 主流程

触发源：HTTP（运营）或定时任务（每日凌晨 4 点，仅 wechat 环境）；终态：ATP 与 WTA 前 200 名球员资料已新增或刷新。

1. 分别从 `app.atptour.com` 和 `wta-webapi-prod-apimanagement.azure-api.net` 取得 ATP、WTA 第 1 至第 200 名球员排名。
2. 将每名球员整理为所属巡回赛、外部球员编号、姓名、国家或地区、出生日期、当前排名和积分。
3. 以 `tour` 与 `player_id` 共同识别球员，新增尚未收录的球员，并刷新已收录球员本次来源提供的非空资料。
4. 先完成 ATP 球员更新，再完成 WTA 球员更新；两类排名均处理后向运营交付排名采集完成结果，定时触发则结束当日采集。

## 分支与异常

| 什么情况 | 怎么处理 | 对外提示 | 做了一半的怎么收场 |
|---|---|---|---|
| 定时任务运行环境不是 `wechat` | 不发起当日排名采集 | 无 | 不产生变更 |
| ATP 排名来源无响应、返回空数据或没有球员 | 跳过 ATP 更新，继续处理 WTA | HTTP 仍可能返回“排名采集完成”；定时任务无提示 | ATP 既有资料保持原状，WTA 可正常更新 |
| WTA 排名来源无响应、返回空数据或没有球员 | 跳过 WTA 更新 | HTTP 仍返回“排名采集完成”；定时任务无提示 | 已完成的 ATP 更新保留，WTA 既有资料保持原状 |
| 来源记录缺少 `player_id` | 不保存该名球员 | 无 | 同批其他可识别球员照常保存 |
| 来源出生日期为空或无法识别 | 不刷新该球员的 `birth_date` | 无 | 既有出生日期保留；新球员的出生日期为空 |
| 来源的其他球员资料字段为空 | 已收录球员保留该字段旧值；新球员按来源现状保存 | 无明确提示 | 同批其他非空资料仍可更新；必填姓名为空时整批保存可能失败 |
| ATP 数据读取或保存发生未处理异常 | 本次采集中断，不再处理 WTA | HTTP 返回调用失败；定时任务无业务提示 | ATP 当批保存失败时撤销该批变更，既有资料保持原状 |
| WTA 数据保存发生异常 | 本次采集中断 | HTTP 返回调用失败；定时任务无业务提示 | 已完成的 ATP 更新保留，WTA 当批变更撤销 |

## 业务边界

- 负责采集 ATP 与 WTA 第 1 至第 200 名球员的排名、积分及随排名来源提供的基础资料。
- 负责按 `tour` 与 `player_id` 新增或刷新 `tour_player`；ATP 与 WTA 编号即使相同也视为不同球员身份。
- 不负责采集第 200 名以后的球员，也不负责删除本次来源中未出现的存量球员。
- 不负责维护签表、赛程、赛况、赛果、种子和球员赛事路径。
- 不负责写入或刷新球员的性别与持拍手资料。

## 遗留与待定

- 排名范围固定为第 1 至第 200 名，代码未说明这一上限的业务依据；覆盖范围由职业赛事数据负责人确认。
- 每日定时采集固定只在 `wechat` 环境运行，其他环境是否需要采集及环境对应的业务含义由运营与研发确认。
- ATP 与 WTA 顺序处理，前者成功、后者失败时会留下两个巡回赛更新时间不同的排名快照；是否需要标记快照日期和完整性由职业赛事数据负责人确认。
- 本次来源未出现的球员不会清空旧排名，也不会被标记为掉出前 200 名；排名失效和历史留存规则由职业赛事数据负责人确认。
- 来源字段为空时不会清除既有资料，因此外部明确撤回或更正为空无法反映；空值覆盖规则由职业赛事数据负责人确认。
- `first_name`、`last_name` 在 `tour_player` 中必填，但采集链没有缺失姓名的替代规则；姓名缺失时如何保存由职业赛事数据负责人确认。
- 数据源没有提供性别与持拍手，本服务也不按 ATP/WTA 推导 `gender`；这两个字段的补齐责任由职业赛事数据负责人确认。
- 两个触发入口都不返回新增数、更新数、跳过数或分巡回赛结果；运营可见的成功与部分成功标准由产品确认。
- HTTP 入口未体现运营身份校验，哪些账户可以手动发起排名采集由平台安全与业务负责人确认。
