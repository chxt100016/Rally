## 一句话价值

为用户交付球员在指定签表中的晋级与潜在对阵路径

## 核心概念

- 职业赛事  从公开数据源采集的 ATP/WTA 赛事，用于赛程、比分和内容展示，不接受本产品用户报名。
- 签表  职业赛事的参赛位置、轮次结构和潜在晋级路径。
- 种子  职业赛事中用于体现重点球员及签表排序的编号。
- 晋级路径  球员在指定签表中已经获胜的比赛，按轮次先后组成的路线。
- 潜在对手  球员尚未出局时，依据签表位置、种子号和已有赛果推算的后续轮次候选对手，不代表对阵已经确定。

## 业务对象

### 球员赛事路径

| 业务名称 | 描述 | 取值说明 |
|---|---|---|
| 球员 | 所查球员的编号、姓名、国家或地区、排名、积分、年龄及种子号。 | — |
| 已晋级路径 | 球员已经获胜的完赛比赛，按轮次顺序展示。 | — |
| 出局信息 | 球员最后一场完赛败局；没有败局时为空。 | — |
| 下一场 | 未出局球员的实际下一位对手，或按签表推算的种子候选对手。 | — |
| 后续潜在对手 | 从下一场之后逐轮推算的种子候选对手；已出局时为空。 | — |

### 比赛路径条目

| 业务名称 | 描述 | 取值说明 |
|---|---|---|
| 比赛轮次 | 比赛轮次简称及中文名称。 | 一百二十八强、一百强以内的特殊轮次、六十四强、三十二强、十六强、八强、半决赛或决赛。 |
| 对手 | 实际或候选对手的编号、展示姓名、国家或地区及种子号。 | — |
| 比分或排期 | 完赛时展示本人视角逐盘比分；待赛时展示日期、时间和球场；信息不足时显示已完成或待定。 | — |
| 路径结果 | 表示所查球员在该路径节点的结果。 | 获胜：赢得完赛比赛；失利：输掉完赛比赛；待定：比赛未完成或对手尚未确定。 |

## 状态机

无。本服务查阅已有职业赛事数据，不改变签表、球员、参赛资料或比赛状态；缺少译文时只登记待译条目。

## 主流程

触发源：HTTP（用户或匿名访问者）；终态：指定球员在所选签表中的晋级、出局和潜在对阵路径已交付。

1. 用户指定外部赛事编号、赛事年份、球员编号和签表类型，定位唯一签表与球员资料。
2. 补充所查球员在该签表中的种子号、当前排名、积分、国家或地区，并依据出生日期计算查询当天的年龄。
3. 取得该签表全部比赛及所查球员参与的比赛，为路径涉及的球员补充姓氏、国家或地区与种子资料。
4. 将所查球员的比赛按轮次序号升序排列；每场状态为 `FINISHED` 且胜方是该球员的比赛进入晋级路径，比分按该球员视角展示。
5. 若球员在任一已结束比赛中落败，将最后处理到的败局作为出局信息，不再交付下一场和更远轮次的潜在对手。
6. 若球员尚未出局，优先把已排定但未结束比赛中的另一方作为下一场对手；没有未结束比赛时，从最近胜场的相邻签表分支中选择未被淘汰的最高种子作为下一轮候选对手。
7. 从下一场之后继续沿签表逐轮向决赛方向推算；每轮从对手分支选择未被淘汰的最高种子，形成更远轮次的潜在对手，找不到符合条件的种子时跳过该轮。
8. 球员与对手姓名、下一场球场有简体中文译文时使用译名；没有译文时保留原文并登记待译条目，最终一并交付球员资料、晋级路径、出局信息、下一场和潜在对手。

## 分支与异常

| 什么情况 | 怎么处理 | 对外提示 | 做了一半的怎么收场 |
|---|---|---|---|
| 缺少任一必填查询条件 | 拒绝本次查询 | 具体文案未在本入口定义；年份类型错误时提示“参数类型错误” | 不改变职业赛事数据 |
| 没有匹配赛事编号、年份和签表类型的签表 | 查询成功但结果主体为空 | 无错误提示 | 不改变职业赛事数据，也不登记待译条目 |
| 没有所给球员编号的职业球员资料 | 查询成功但结果主体为空 | 无错误提示 | 不改变职业赛事数据，也不登记待译条目 |
| 球员在签表中没有参赛资料 | 球员种子号为空，仍按已有比赛形成路径 | 无 | 其余球员资料与路径照常交付 |
| 球员在签表中没有任何比赛 | 交付球员资料，晋级路径和潜在对手为空，出局信息与下一场为空 | 查询成功 | 不改变职业赛事数据；球员姓名可登记待译条目 |
| 比赛状态不是精确的 `FINISHED` | 当作未结束比赛，可能被选为下一场 | 无 | 其他路径照常交付 |
| 未结束比赛尚未确定另一方球员 | 不交付 `next`，仍可从签表后续分支推算更远轮次候选 | 无 | 晋级和其他潜在路径照常交付 |
| 已结束比赛没有逐盘比分 | 比分显示“已完成” | 无 | 胜负、晋级或出局仍按 `winner_id` 判断 |
| 对手没有职业球员资料 | 以外部球员编号作为展示姓名，国家或地区为空 | 无 | 该场路径与其他资料照常交付 |
| 对手没有种子资料 | 实际对阵仍可交付，种子号为空；潜在轮次不把该球员选为候选 | 无 | 其他实际或候选对手照常交付 |
| 国家或地区三字码不在已知清单 | 原码同时作为代码和名称交付，旗帜代码为空 | 无 | 其他球员资料照常交付 |
| 轮次名称缺失 | 下一场或潜在轮次按签表位置推算轮次；完赛路径的轮次及中文名为空 | 无 | 其他路径资料照常交付 |
| 轮次名称不在已知范围内 | 保留原轮次名称，中文轮次名为空 | 无 | 其他路径资料照常交付 |
| 下一场没有计划时间、比赛日期、来源排期文本和球场 | 排期显示“待定” | 无 | 对手与轮次仍照常交付 |
| 球员姓名或下一场球场没有简体中文译文 | 保留原文并登记待译条目 | 无 | 已有译文仍正常使用，查询结果照常交付 |
| 查询、比分解析或资料组装失败 | 本次查询失败 | 系统异常，请稍后重试 | 职业赛事数据不变；失败前登记的待译条目是否保留取决于发生时点 |

## 业务边界

- 负责按赛事编号、年份、签表类型和球员编号交付一名职业球员的赛事路径。
- 负责交付球员资料、已胜比赛、出局败局、下一场对手及更远轮次的种子候选对手。
- 负责从所查签表的已有比赛判断胜负与淘汰，并按所查球员视角展示逐盘局分。
- 负责使用已有简体中文球员姓名和下一场球场译文，并为缺少的译文登记待译条目。
- 不负责采集、刷新或纠正职业赛事、签表、球员、参赛资料、比赛和比分。
- 不负责生成译文；新登记的待译条目由“待译内容批处理”继续处理。
- 不负责保证潜在对手最终晋级，也不把候选对阵写回签表或赛程。
- 不负责职业球员名录的排名列表查询；该承诺属于“职业球员查询”。

## 遗留与待定

- 签表类型由用户原样提供且没有取值校验；数据库说明使用 `WS` 表示女子单打，现有 WTA 采集资料使用 `LS`，统一口径需职业赛事数据负责人确认。
- `tour_player` 以 `player_id` 与 `tour` 共同唯一，但所查球员和对手资料都只按 `player_id` 读取；ATP 与 WTA 编号重复时会出现多条资料并令查询失败，关联口径需职业赛事数据负责人确认。
- 所查球员种子按指定签表读取，但对手种子会合并同一 `tournament_id` 下所有年份和签表，并在同一球员出现多个种子号时采用先取得的一条；对手种子应按哪一届、哪一签表隔离需职业赛事数据负责人确认。
- 种子读取不区分参赛资料的 `status` 或 `entry_type`，`WITHDRAWN`、`RETIRED` 等记录只要有非零种子号也可能成为球员资料或潜在对手；参赛有效性口径需职业赛事数据负责人确认。
- “当前比赛”取轮次排序后的第一场未结束比赛；同一球员同时存在多场未结束记录时，没有按日期、签表位置或状态决定优先级，选择规则需产品确认。
- 球员只要在任一 `FINISHED` 比赛中不是胜方即判定已出局；没有校验 `winner_id` 是否属于对阵双方，也没有处理退赛、取消等独立赛果，淘汰判定标准需职业赛事数据负责人确认。
- 同一球员若存在多条完赛败局，出局信息取轮次排序后最后处理的一条；多败局数据的展示和纠错规则需职业赛事数据负责人确认。
- 潜在对手固定选择相邻签表分支中未淘汰且种子号最小的球员，所有非种子球员都不会成为潜在候选；这一预测策略的业务依据需产品确认。
- 后续轮次只在找到种子候选时交付，找不到候选的中间轮次直接缺失；是否需要保留“对手待定”的轮次占位需产品确认。
- 缺少 `round_name` 时按 `match_index` 的二叉树层级推算 `F`、`SF`、`QF` 或 `R` 加人数；该规则没有使用签表的 `size`、`total_rounds`，也无法推算 `R96`，适用签表范围需职业赛事数据负责人确认。
- `match_index` 没有数据库唯一约束；同一签表出现重复位置时只采用先取得的比赛，哪条记录有效需职业赛事数据负责人确认。
- 晋级路径按 `round_number` 升序，空轮次序号按 `0` 排在最前；相同轮次没有稳定的次级顺序，展示顺序需产品确认。
- 完赛比分按 `sets_json` 当前数组顺序拼接，不按 `setNumber` 排序且不展示抢七分；比分完整性和抢七展示规则需产品确认。
- 主球员姓名使用名与姓的组合，对手姓名只使用姓；不同姓名文化与对手重名时的展示规则需产品确认。
- 球员头像当前固定为空；头像来源和补齐责任需产品确认。
- 年龄按每次查询当天根据出生日期重新计算，不标注统计日期；年龄展示口径需产品确认。
- 下一场排期直接拼接来源排期文本和球场场次序号，没有统一解释 `scheduled_at_text` 的枚举或格式；展示规范需产品确认。
- 空的 `translated_text` 会保留原文，只有下一场球场参与翻译，晋级与出局条目不携带球场；翻译覆盖范围和译文生效时点需内容负责人确认。
