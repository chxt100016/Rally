## 一句话价值

按城市与登录状态向访问者交付配置化首页内容。

## 核心概念

- 首页区域  首页中可配置顺序和内容类型的独立展示单元，如约球、赛事、海报或资讯。
- 约球  围绕一次明确时间、场地、人数和参与条件组织的网球活动，不只是两人邀约。
- 职业赛事  从公开数据源采集的 ATP/WTA 赛事，用于赛程、比分和内容展示，不接受本产品用户报名。
- 城市感知海报  会随本次查询城市改变标题或导航目标的首页海报。
- 登录身份  本次访问能够识别出的账户身份，仅影响“我的约球”区域是否交付本人数据。

## 业务对象

### 首页区域

| 业务名称 | 描述 | 取值说明 |
|---|---|---|
| 区域类型 | 决定该区域交付的首页内容。 | 我的约球：本人最多十条进行中约球；职业赛事：当前赛事及近期比赛；海报卡片：自办赛事、城市球场或自定义海报；资讯时间线：当前交付空清单。 |
| 标题 | 区域的主标题，来自配置、预设文案或业务数据。 | — |
| 副标题 | 区域的补充说明，来自配置、预设文案或业务数据。 | — |
| 约球内容 | 本人的进行中约球卡片；匿名访问时为空。 | 包含约球、人数、城市区域、时间、场地和水平要求等展示信息。 |
| 职业赛事内容 | 按同期同城归组后的代表赛事及比赛。 | 包含赛事、巡回赛、场地、比赛日期、球员、种子、比分和胜者等展示信息。 |
| 海报内容 | 区域包含的海报清单。 | 包含交互方式、图片、标题、副标题及各端跳转目标。 |
| 资讯内容 | 区域包含的资讯清单。 | 当前固定为空清单。 |

## 状态机

无

## 主流程

触发源：用户或匿名访问者发起 HTTP 查询；终态：按城市、登录身份和当前配置交付首页区域列表。

1. 接收可选城市编码和可选登录身份；城市未填写时采用默认城市。
2. 取得首页区域配置，按配置顺序处理所有未明确停用且类型可识别的区域。
3. 对“我的约球”区域，匿名访问交付空约球列表；已登录访问交付本人仍有效参与、处于报名中且尚未结束的前 10 条约球卡片，并补充区域标签和场地背景。
4. 对自办赛事海报、城市球场海报和自定义海报区域，交付标题、副标题、七牛云图片地址和各端交互目标；城市感知海报同时带入本次城市编码和城市名称。
5. 对职业赛事区域，找出当前日期附近仍在举办、符合级别范围且有近期比赛的赛事，合并同期同城项目，并按赛事级别和日期排列。
6. 每个职业赛事组交付一项代表赛事，以及最近比赛日期中首个球场的比赛；赛事名、球场名和球员名优先使用已有简体中文译文，没有译文时保留原文。
7. 对资讯区域交付区域标题、副标题和当前资讯列表。
8. 省略无法形成的区域，其余区域保持配置顺序，交付完整首页结果。

## 分支与异常

| 什么情况 | 怎么处理 | 对外提示 | 做了一半的怎么收场 |
|---|---|---|---|
| 未传城市编码或城市编码仅含空白 | 使用 `330100` 作为本次城市 | 无 | 继续交付全部可形成的区域。 |
| 匿名访问 | “我的约球”交付空列表 | 无 | 其他首页区域照常交付。 |
| 首页 JSON 配置无法解析 | 使用相应内置默认配置 | 无 | 继续按默认配置交付。 |
| 某区域明确停用 | 不交付该区域 | 无 | 其他区域照常交付。 |
| 某区域缺少类型、类型不支持或构建失败 | 省略该区域 | 无 | 已形成及后续区域继续交付。 |
| 城市编码不能在城市名录中识别 | 省略城市球场海报；城市感知的自定义海报仍交付区域，但海报可能为空 | 无 | 不依赖城市名称的区域继续交付。 |
| 海报配置为空 | 交付空海报列表 | 无 | 对应区域仍可交付标题和副标题。 |
| 海报列表中出现无法识别的交互方式或无效配置 | 终止该海报列表的继续处理，保留此前已形成的海报 | 无 | 对应区域及其他区域继续交付。 |
| 没有当前职业赛事 | 省略职业赛事区域 | 无 | 其他区域照常交付。 |
| 某组职业赛事没有近期比赛、比赛日期、球场或可展示对阵 | 省略该赛事组 | 无 | 继续处理其他赛事组；全部为空时省略职业赛事区域。 |
| 职业比赛只有一方球员已确定 | 仍交付该比赛，未确定的一方为空 | 无 | 其他比赛不受影响。 |
| 职业比赛双方均未确定 | 不交付该比赛 | 无 | 该组无其他可展示比赛时省略该赛事组。 |
| 赛事名、球场名或球员名没有简体中文译文 | 保留原文，并登记为待译内容 | 无 | 首页仍以原文完成交付。 |
| 资讯区域启用 | 交付空资讯列表 | 无 | 其他区域照常交付。 |
| 首页配置、约球、场地、职业赛事、比赛、球员或种子资料整体读取失败 | 受影响区域被省略 | 无 | 已形成及后续区域继续交付。 |

## 业务边界

本服务负责把当前首页配置、查询城市、可选登录身份、本人进行中约球、自办赛事海报、职业赛事与比赛、城市球场海报、自定义海报及资讯组合成有序首页区域，到返回完整区域列表或空列表为止。它不维护首页配置，不开通或校验城市业务，不提供约球详情或报名操作，不维护赛事、赛程与赛果，不执行翻译，也不维护资讯内容；海报点击后的页面访问属于相应业务服务。

## 遗留与待定

- 未传城市时固定使用城市编码 `330100`，默认城市的产品依据及变更责任未说明，需产品确认。
- 内置首页布局固定包含“我的约球、自办赛事海报、职业赛事、城市球场海报、资讯”五个区域，内置海报还固定了数量、文案、图片和导航目标；这些默认内容的维护责任和有效期需运营确认。
- 首页“我的约球”固定取 10 条、按业务编号倒序且不提供续页标识，数量和排序依据需产品确认。
- 首页“我的约球”只接受约球状态 `OPEN`，却把报名状态 `REVIEWED`、`SKIPPED` 也视为有效参与；该组合是否可能且是否应展示需约球负责人确认。
- 约球卡片背景暂未使用实时天气，室外场地固定采用晴天样式；天气数据来源与启用时机需产品确认。
- 职业赛事查询把开始日前一天至结束日后一天都视为“当前”，日期缓冲的业务依据需内容负责人确认。
- 数字型赛事级别低于 250 的记录会被排除，空值和非数字级别却保留；筛选口径需职业赛事数据负责人确认。
- 同城且日期重叠的 ATP、WTA 或其他巡回赛记录会合并为一组；城市名称大小写比较、日期重叠和跨巡回赛合并是否足以代表同一赛事需内容负责人确认。
- 赛事组固定按 `GS`、`1000`、`500`、`250` 排在其他级别之前，并以排序首项作为代表赛事；排序和代表项选择依据需内容负责人确认。
- 每个赛事组只展示最近日期的首个球场及该球场比赛，而不是该日期全部球场；该截取规则和球场排序依据需产品确认。
- 职业赛事区域副标题把记录数量称为“场ATP/场WTA”，统计单位不是比赛场次；展示口径需产品与内容负责人确认。
- 比赛日期分组会把数据中早于今天的最早日期称为“今天”，并以此顺延“明天”；跨日展示语义需产品确认。
- 比赛状态为空的记录也可能被当作未完赛读取，但 `tour_match.status` 的表定义为必填；兼容规则是否仍需要需职业赛事数据负责人确认。
- 首页查询遇到缺少译文的赛事名或球场名会新增 `translated_text` 为空的 `translation` 条目；查询服务产生待译数据是否符合业务边界需内容负责人确认。
- 城市感知海报会无条件在导航目标后附加城市信息；已有查询参数时如何组合、城市名称是否需要编码以及各端约定未说明，需客户端与产品确认。
- 资讯区域当前永远交付空列表，资讯来源、筛选范围和启用条件尚未实现，需产品与内容负责人确认。
