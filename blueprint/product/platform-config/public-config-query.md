## 一句话价值

向登录用户交付一个或多个配置标识的当前值。

## 核心概念

- 配置标识  用于唯一指定某项配置的字符串，通常按业务域、模块和属性分段。
- 当前配置值  已启用的保存值优先；没有可用保存值时，已登记配置使用内置默认值。
- 配置覆盖  在全局作用域下保存并启用的值，用来取代同一配置标识的内置默认值。

## 业务对象

### 公共配置

| 业务名称 | 描述 | 取值说明 |
|---|---|---|
| 配置标识 | 指定要查询的一项或多项公共配置。 | — |
| 当前值 | 当前可供业务使用的配置内容；已启用的保存值优先，已登记配置可回退到默认值。 | 单项查询无可用值时为空；批量查询只包含能够取得当前值的配置。 |

## 状态机

无

## 主流程

触发源：登录用户发起单个配置标识 HTTP 查询，或发起批量配置标识 HTTP 查询；终态：可取得的当前配置值已交付，不改变配置状态。

1. 用户提交一个配置标识，或一组配置标识。
2. 对每个配置标识取得当前生效的保存值。
3. 没有可用保存值时，若该标识已登记，则使用其内置默认值。
4. 单项查询交付该标识的字符串值；批量查询交付所有可取值标识及其字符串值的映射。

## 分支与异常

| 什么情况 | 怎么处理 | 对外提示 | 做了一半的怎么收场 |
|---|---|---|---|
| 未提供登录凭证 | 拒绝查询 | `登录已过期，请重新登录` | 只读查询，不产生业务变更 |
| 登录凭证无效 | 拒绝查询 | `登录凭证无效，请重新登录` | 只读查询，不产生业务变更 |
| 单项查询的标识既无可用保存值又未登记默认值 | 查询成功，交付 `null` | 无专门提示 | 只读查询，无需收场 |
| 批量查询中某个标识既无可用保存值又未登记默认值 | 省略该标识，继续交付其他可取值项 | 无专门提示 | 只读查询，无需收场 |
| 没有已启用的保存值，但配置标识已登记默认值 | 交付内置默认值 | 查询成功 | 只读查询，无需收场 |
| 批量请求为空列表 | 交付空映射 | 查询成功 | 只读查询，无需收场 |
| 查询标识缺失、批量请求缺失，或批量列表含 `null` | 终止本次查询 | `系统异常，请稍后重试` | 只读查询，已取得的局部值不交付 |
| 配置资料无法取得 | 终止查询 | `系统异常，请稍后重试` | 只读查询，不产生业务变更 |

## 业务边界

本服务只按用户提供的标识交付当前配置字符串，不负责枚举全部配置、交付配置说明、类型或版本，也不负责修改、校验或解析配置内容。单项和批量入口属于同一业务承诺。

## 遗留与待定

- 公共查询没有可查配置白名单；登录用户只要知道标识，就可取得任意已启用的配置值。哪些配置可对用户公开，需产品与安全负责人确定。
- 当前输入既可按普通配置标识读取全局值，也可能直接命中带作用域的保存记录；作用域限定标识是否属于正式对外规则，需产品与安全负责人确定。
- 不存在的标识在单项查询中交付 `null`，在批量查询中却被省略；缺失值的统一业务口径需产品确定。
- 批量查询没有数量上限，也没有对空白、重复或 `null` 标识的独立处理规则；需产品确定数量上限、输入规范与错误口径。
- 配置值一律以字符串交付，字符串应按何种类型解析没有随结果提供；调用方如何获得稳定类型契约，需产品与各配置负责人确定。
