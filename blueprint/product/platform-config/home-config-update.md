## 一句话价值

让运营校验并发布首页区域与海报的新配置

## 核心概念

- 首页区域  首页中可配置顺序和内容类型的独立展示单元，如约球、赛事、海报或资讯。
- 配置覆盖值  运营发布并启用的配置值；不存在启用值时，首页采用预置默认值。
- 配置版本  标识运营读取时配置版本的整数，用于避免后来提交的修改被旧页面覆盖。

| 配置内容 | 与配置类别对应、经校验后发布的首页内容。 | — |
| 配置版本 | 用于确认修改基于哪个版本；首次发布使用零，成功后版本递增。 | — |
| 启用状态 | 表示运营设置是否作为当前内容生效；本服务成功后会启用。 | 已启用：采用运营设置；已停用：采用默认内容。 |
| 当前值来源 | 表示发布后的内容来自运营设置还是默认内容。 | 已覆盖：采用运营设置；未覆盖：采用默认内容。 |

## 交付内容

类型: 变更类

成功后按主流程改写或撤销既有业务事实；允许变更的内容、前置状态、对外可见结果与原值留痕，以本节下列规则、业务对象及分支与异常为准。

## 主流程

触发源：HTTP（运营）；终态：新首页配置已发布并交付三类首页配置的最新全量视图。

1. 运营提交配置标识、JSON 配置内容和自己读取到的版本。
2. 确认本次修改属于首页区域布局、自办赛事海报或通用海报，并按对应内容结构校验区域和海报。
3. 首次发布时建立启用的全局覆盖值并将版本记为 `1`；修改已有覆盖值时确认版本未落后，再保存新值并将版本加 `1`。
4. 发布新配置，使后续首页读取采用新的覆盖值。
5. 交付三类首页配置各自的当前值、默认值、版本和覆盖状态。

## 分支与异常

| 什么情况 | 怎么处理 | 对外提示 | 做了一半的怎么收场 |
|---|---|---|---|
| 调用方没有有效运营凭据 | 拒绝修改 | 拒绝访问 | 不产生配置变更 |
| 配置标识为空、内容缺失或版本缺失 | 拒绝修改 | 对应字段不能为空 | 不产生配置变更 |
| 配置标识不属于三类首页配置 | 拒绝修改 | 该配置不允许在首页配置中心修改 | 不产生配置变更 |
| 配置内容超过规定长度，或不是对应结构的有效 JSON | 拒绝修改 | 配置内容不能超过 100KB，或配置格式无效 | 不产生配置变更 |
| 首页区域配置为 `null`、超过 30 个，区域格式错误，或区域标识缺失、重复、超长、含非法字符 | 拒绝修改 | 指明首页区域数量、位置或标识问题 | 不产生配置变更 |
| 首页区域类型不受支持，或非自定义海报区域的同一类型重复 | 拒绝修改 | 指明不支持或重复的区域类型 | 不产生配置变更 |
| 自办赛事海报区缺少标题或副标题，自定义海报区缺少标题，或海报清单缺失 | 拒绝修改 | 指明缺失的标题、副标题或海报清单 | 不产生配置变更 |
| 单个区域超过 20 张海报，海报格式错误，类型不是 `NAVIGATE` 或 `PREVIEW`，或图片 key 为空 | 拒绝修改 | 指明海报数量、位置、类型或图片问题 | 不产生配置变更 |
| 首次发布所带版本不是 `0`，或已有配置的版本已被其他修改推进 | 拒绝覆盖现有结果 | 配置已被其他人修改，请刷新后重试 | 不产生配置变更 |
| 首次配置记录保存失败 | 返回失败 | 配置保存失败 | 本次发布整体不成立 |

## 业务边界

本服务只负责发布全局范围的首页区域布局、自办赛事海报和通用海报配置，并返回三类配置的最新全量视图。它不负责查询首页配置、维护其他全局配置、上传海报图片，也不保证配置引用的图片和跳转目标实际可用；首页内容查询负责按已发布配置组装最终页面。

## 遗留与待定

| 等级 | 待定的是什么 | 要谁来定 |
|---|---|---|
| P1 | 内容长度按 100,000 个字符校验并对外称为 100KB，但 `sys_config.config_value` 只有 VARCHAR(2048)；实际可发布上限及计量单位需产品与数据负责人统一。 | 产品与平台运营负责人 |
| P1 | 30 个首页区域、每区 20 张海报、区域标识 64 位及其字符范围均为写死校验，代码未说明业务依据，需产品确认。 | 产品与平台运营负责人 |
| P2 | 六种首页区域类型、两种海报类型，以及除 `POSTER` 外同类区域只能出现一次均为写死规则，缺少产品规则来源和扩展机制，需产品确认。 | 产品与平台运营负责人 |
| P2 | 空的区域清单和空的海报清单当前可以发布；是否至少保留一个区域或一张海报需产品确认。 | 产品与平台运营负责人 |
| P1 | 首页区域只严格校验 `id`、`type` 及部分海报字段；`enabled`、`cityAware` 的类型和其他区域所需字段没有完整校验，需产品确定各类型的必填结构。 | 产品与平台运营负责人 |
| P2 | 海报跳转地址、七牛云图片对象 key 及其实际可用性不在发布时核验，错误引用应阻止发布还是允许首页容错需产品确认。 | 产品与平台运营负责人 |
| P2 | 发布只明确刷新处理本次修改的运行节点，多个运行节点之间何时采用新值没有统一发布口径，需产品与技术负责人确认。 | 产品与平台运营负责人 |
| P2 | 配置记录没有保存修改人和变更原因，运营修改的审计与追责要求需产品和运营确认。 | 产品与平台运营负责人 |
