## 一句话价值

为用户或访客分页交付指定城市当前可参与的约球。

## 核心概念

- 约球  围绕一次明确时间、场地、人数和参与条件组织的网球活动，不只是两人邀约。
- 约球广场  按城市汇集仍在报名期且尚未结束的约球，供用户或访客查阅。
- 可参与约球  状态为报名中且结束时间晚于查询时刻的约球；当前查询不另行校验是否满员或查询者本人能否报名。

## 状态机

无

## 主流程

触发源：用户或匿名访客按时间或距离发起 HTTP 查询；终态：交付一页符合条件的约球卡片及续页标识。

1. 接收城市、排序、分页位置及可选的类型、时间、水平和距离条件。
2. 找出该城市中状态为报名中且尚未结束的约球。
3. 按约球类型和开球时间范围进一步筛选；查询水平上下限均存在时，保留与查询水平区间有交集的约球。
4. 查询限定半径时，保留距查询位置不超过该半径的约球。
5. 选择时间排序时按开球时间从早到晚排列；选择距离排序时按场地从近到远排列。
6. 从上一页位置之后截取本页约球，并判断是否还有下一页。
7. 为每项约球补充区域主标签和卡片背景样式；有查询位置时补充到场地的距离。
8. 交付约球卡片列表；仍有数据时同时交付下一页续查标识。

## 分支与异常

| 什么情况 | 怎么处理 | 对外提示 | 做了一半的怎么收场 |
|---|---|---|---|
| 城市编码为空或只含空白字符 | 拒绝查询 | `cityCode: 请选择城市` | 未修改任何业务数据。 |
| 未选择排序方式 | 拒绝查询 | `sort: 请选择排序方式` | 未修改任何业务数据。 |
| 每页数量小于 1 | 拒绝查询 | `pageSize: 每页数量最小为1` | 未修改任何业务数据。 |
| 按距离排序但未同时提供经纬度 | 拒绝查询 | `参数错误` | 未修改任何业务数据。 |
| 按时间排序并限定半径，但未同时提供经纬度 | 拒绝查询 | `参数错误` | 未修改任何业务数据。 |
| 选择推荐排序 | 交付空列表，且无下一页 | 无 | 未修改任何业务数据。 |
| 没有符合条件的约球 | 交付空列表，且无下一页 | 无 | 未修改任何业务数据。 |
| 续页标识为空或无法识别 | 按首页重新交付 | 无 | 未修改任何业务数据，可能与已看内容重复。 |
| 距离排序的续页约球已不在当前结果中 | 从当前结果首页重新交付 | 无 | 未修改任何业务数据，可能与已看内容重复。 |
| 关联球场不存在或没有环境、材质 | 继续交付卡片，背景按室外硬地晴天样式补足 | 无 | 未修改任何业务数据。 |
| 约球、球场或距离资料读取失败 | 查询失败 | `系统异常，请稍后重试` | 未修改任何业务数据。 |

## 业务边界

本服务负责向用户或匿名访客交付指定城市当前报名中、尚未结束的约球卡片，到当前页或空页以及续页标识交付为止。按时间与按距离只是同一承诺的两种触发参数，不拆成不同服务。本服务不负责发布或修改约球，不判断查询者是否满足性别、NTRP、信誉、时间冲突等报名条件，不保证约球仍有空位，不建立报名关系，也不交付约球详情、发布者和参与者资料。

## 遗留与待定

- `RECOMMEND` 已作为排序取值开放，但没有推荐规则，当前直接交付空页；是否下线该取值或补充推荐口径，应由产品确认。
- `tags` 已作为查询条件开放但未参与筛选；标签的来源、匹配方式和是否启用，应由产品确认。
- 查询条件 `levelMode` 未参与筛选；当前只在 `levelMin` 与 `levelMax` 同时存在时按区间交集筛选，单边条件会被忽略，水平筛选口径应由产品确认。
- 查询未排除 `current_players` 已达到 `max_players` 的约球，也不校验查询者本人是否可报名；“可参与约球”是否应包含这些约球，应由产品确认。
- 查询不按 `meetup_type` 区分普通约球和赛事赛约；赛事赛约是否应出现在约球广场，应由产品与赛事负责人确认。
- `radiusKm`、经度、纬度没有正负值和有效范围校验；合法范围及越界提示应由产品确认。
- `startTime` 晚于 `endTime`、`levelMin` 大于 `levelMax` 时没有明确校验，只会交付空页或产生不符合预期的筛选；参数约束应由产品确认。
- `pageSize` 没有最大值，显式传空值也没有业务提示；单页上限与空值处理应由产品确认。
- 时间排序的续页标识若能解码但内容数量或时间格式不正确，可能被当作首页或返回系统异常；续页失效的统一提示与恢复方式应由产品确认。
- 卡片背景暂未使用实时天气，室外场地固定按晴天样式交付；天气维度何时启用以及数据来源，应由产品确认。
- 卡片背景以 06:00—17:00 为白天、17:00—19:00 为黄昏、19:00—次日 06:00 为夜间，代码未说明该分段的业务依据和时区，应由产品与视觉负责人确认。
- 分页结果的 `total` 没有对应数据来源，当前固定为空；是否保留以及是否需要总量，应由产品确认。
