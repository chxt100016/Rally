## 一句话价值

让参与者按当前版本修正可复盘约球的一盘比分。

## 核心概念

- 约球  围绕一次明确时间、场地、人数和参与条件组织的网球活动，不只是两人邀约。
- 约球报名  用户与约球之间的参与关系，可处于待审批、已加入、已拒绝、已撤回、已退出、已评价或已跳过。
- 赛后复盘  约球结束后记录比分、评价同场用户或明确跳过评价的阶段。
- 比分版本  用于确认修改所依据的比分仍是当前内容的编号；提交版本与现值不一致时拒绝修改。

## 业务对象

### 比分记录

| 业务名称 | 描述 | 取值说明 |
|---|---|---|
| 比分编号 | 唯一标识本次修改的一盘比分。 | — |
| 所属约球 | 本盘比分对应的约球。 | — |
| 盘号 | 本盘在该约球全部比分中的顺序，同一约球内不可重复。 | — |
| 比赛类型 | 表示本盘采用单打或双打阵容。 | 单打：每侧一名球员；双打：每侧两名球员。 |
| 盘制 | 表示本盘采用的计分方式。 | 常规局：按局数记录得分；抢分局：按抢分分数记录得分。 |
| 双方阵容 | 修改后两侧参与本盘比赛的球员及其展示资料。 | — |
| 双方得分 | 修改后两侧在本盘取得的分数。 | — |
| 获胜方 | 根据修改后的双方得分确定的本盘胜方。 | 甲方：甲方得分更高；乙方：乙方得分更高。 |

## 状态机

无。比分修改只替换现有一盘的内容，不改变其业务状态。

## 主流程

触发源：参与者 HTTP 请求；终态：指定比分保持原编号并成为修正后的当前内容。

1. 确认约球存在，并取得活动时间、状态、发布者及报名关系。
2. 确认修改人属于该约球，且约球处于可复盘阶段并未超过复盘期限。
3. 按约球编号和比分编号找到现有一盘比分。
4. 确认提交的比分版本与当前版本一致。
5. 以提交的盘号、赛制、比赛类型、双方选手及分数组成修正后的比分。
6. 根据双方主分的大小重新确定获胜方，并将修改人记为本次记录人。
7. 以约球开始时间更新比赛日期，并以现有用户资料刷新可取得的选手展示快照。
8. 保存修正后的比分，比分编号和首次创建时间保持不变。

## 分支与异常

| 什么情况 | 怎么处理 | 对外提示 | 做了一半的怎么收场 |
|---|---|---|---|
| 约球编号、比分编号、版本、盘号、赛制、比赛类型、A/B 侧第一位选手或A/B侧主分缺失 | 拒绝修改 | 提示对应必填项不能为空 | 不改变比分。 |
| 约球不存在 | 拒绝修改 | 约球不存在 | 不改变比分。 |
| 修改人既不是发布者，也没有当前规则认可的报名关系 | 拒绝修改 | 你未报名该约球 | 不改变比分。 |
| 约球按当前时间判断后不是进行中或已结束 | 拒绝修改 | 约球不可评价 | 不改变比分。 |
| 当前时间晚于约球结束时间加复盘截止天数 | 拒绝修改 | 评价已超期 | 不改变比分。 |
| 指定比分不属于该约球或比分不存在 | 拒绝修改 | 比分记录不存在 | 不改变比分。 |
| 提交版本与当前比分版本不一致 | 拒绝修改并要求取得最新内容 | 比分版本不一致，请刷新后重试 | 不改变比分。 |
| A、B 两侧主分相同，无法确定胜方 | 拒绝修改 | 获胜边无效 | 不改变比分。 |
| 修改后的盘号与同一约球已有盘号重复 | 修改失败 | 当前没有明确的业务提示 | 单次比分修改不生效，原比分保持不变。 |
| 某位选手没有可取得的用户资料 | 仍保存比分，其展示快照不作可靠刷新 | 无 | 比分修改继续完成。 |

## 业务边界

- 本服务只修改已存在的一盘比分，不新增或删除比分记录。
- 本服务接受约球发布者，以及报名状态为 `PENDING`、`JOINED`、`REVIEWED` 或 `SKIPPED` 的用户发起；其他报名状态无权修改。
- 可复盘条件是约球按当前时间判断为 `ONGOING` 或 `FINISHED`，且当前时间不晚于 `end_time` 加 `review.deadline_days`；该配置默认值为 30 天。
- 本服务按 `rally_meetup_id` 与 `biz_id` 确认比分归属，并要求提交的 `version` 等于当前值。
- 获胜方只按 `side_a_score` 与 `side_b_score` 的大小确定；抢七分不参与获胜方计算。
- 本服务会整体接受提交的盘号、赛制、比赛类型、选手与比分，不限定只能由原记录人修改。
- 本服务不改变约球或约球报名状态，也不自动完成评价或赛后复盘。
- 本服务不重新计算个人评分、胜负统计或其他表现指标。

## 遗留与待定

- 当前实现核对提交版本与现值，但修改内容没有明确产生新版本；修改成功后的版本递增规则及并发修改裁决需产品与研发确认。
- `set_number` 仅有“从 1 开始”的注释，没有范围校验；允许的盘号范围需赛事规则负责人确认。
- 修改后的盘号没有检查同一约球下是否已经存在，可能与“同场同盘唯一”约束冲突；冲突时的业务提示需产品与研发确认。
- 当前没有校验分数非负、常规局与抢分的合法比分、抢七填写条件；各赛制的合法比分规则需网球规则负责人确认。
- 当前只禁止两侧主分相同，并据主分大小判定胜方；抢七分是否应参与胜方判定需网球规则负责人确认。
- 当前没有校验选手是否为约球有效参与者、同一选手是否重复出现，也没有按单打或双打限制人数；合法阵容规则需产品负责人确认。
- 待审批报名当前可以修改比分，但“参与者”注释与实际准入范围不一致；待审批用户是否应有此权限需产品负责人确认。
- 已评价或已跳过评价的用户仍可在期限内修改比分；完成复盘后是否允许继续修改需产品负责人确认。
- 修改比分后的个人评分重算尚未实现；重算触发时点、范围和失败处理需产品负责人确认。
