# tournament.tournament-detail.activity.assemble-tournament-detail 手工路径说明

## 原因

本次需要在赛事详情返回的 `tournament` DTO 上新增 `championUsers`，并定义冠军成员的返回结构。BP scope 仅列出了 `rally-app/src/main/java/com/rally/tournament/` 代码落点，无法只在该目录内改变既有 `TournamentDTO` 的 JSON 契约。

## 必要的 scope 外实现文件

- `rally-domain/src/main/java/com/rally/domain/tournament/model/TournamentDTO.java`
- `rally-domain/src/main/java/com/rally/domain/tournament/model/TournamentChampionUserDTO.java`

这些文件仅承载接口 DTO 字段及成员结构；冠军报名查询、去重、资料补全和头像签名仍由活动实现。
