## 已确认

- [Q1] 字段 null、空串、空对象和清除语义是什么？
  > MapStruct 忽略 null，保留旧值；字符串空串会保存为空，生日/性别不能用 null 清除。空对象或全 null 仍读取并 updateById 后成功。
  → 已写入触发条件、活动契约、业务动作 A2-A3、详细流程第 2-5 步与边界情况

- [Q2] 哪些内容、城市、生日与资源校验实际执行？
  > 不校验字符串长度内容、未来生日、城市存在/开放、头像资源存在归属；只做请求解析与性别/日期类型转换。
  → 已写入详细流程第 4 步与边界情况

- [Q3] 用户定位、保存方式、并发与下游失败回滚如何处理？
  > 只用登录 userId，用户不存在 DATA_NOT_FOUND；读现有对象后全对象 updateById，并发后写可能覆盖。与 getMyProfile 同事务，下游组装异常回滚保存。
  → 已写入异常分支、领域依赖、业务动作 A1/A3、详细流程第 1、5-6 步与实现提示
