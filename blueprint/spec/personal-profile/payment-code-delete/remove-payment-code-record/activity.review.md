## 已确认

- [Q1] 删除记录前为何二次读取，资料不存在时如何返回？
  > 领域删除逻辑再次查询固定扩展键并断言存在；不存在报 USER_EXT_NOT_FOUND，重复删除不是幂等成功。
  → 已写入活动契约、异常分支、详细流程第 1 步与边界情况

- [Q2] 两次读取之间是否校验业务编号或资源 key 一致？
  > 不校验；按二次读取时的 userId 与 extKey 删除，因此并发替换可能导致删旧图片并移除新记录。
  → 已写入详细流程第 2-3 步与边界情况

- [Q3] 数据库失败时如何补偿已删除图片？
  > 数据库事务回滚记录删除，但不补偿也无法恢复七牛图片，可能留下仍引用已删除文件的资料。
  → 已写入异常分支、详细流程第 4 步与实现提示
