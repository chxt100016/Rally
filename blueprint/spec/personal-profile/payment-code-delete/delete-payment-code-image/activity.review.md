## 已确认

- [Q1] 无资料、null 值和空字符串分别如何处理？
  > 无资料或 extValue 为 null 时跳过外部删除并继续；空字符串不是 null，会作为资源 key 调用七牛。
  → 已写入活动契约、详细流程第 2-3 步与边界情况

- [Q2] 七牛文件不存在和其他错误如何处理？
  > 返回码 612 视为已不存在并继续，其他错误按 SYSTEM_ERROR 终止，数据库资料保留但外部实际状态不补偿。
  → 已写入异常分支与详细流程第 4 步

- [Q3] 资源 key 是否校验及外部删除能否事务回滚？
  > 直接删除资料值，不校验格式、类型或归属；七牛不参加数据库事务，成功删除后不可回滚恢复。
  → 已写入详细流程第 3 步、边界情况与实现提示
