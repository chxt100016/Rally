- [Q1] 比分查询、比赛类型和约球筛选采用什么范围？
  > 查询本人位于四个球员位置任一处的全部盘并按 bizId 倒序；matchType 为空保留所有类型，指定时仅 SINGLE/DOUBLE；meetupId 非 null 时完全匹配，空串也是条件。

- [Q2] 游标、页大小、hasMore 和 nextCursor 的精确规则是什么？
  > 游标是 URL-safe Base64 JSON 数组首项 bizId；空白、非法、空数组或未命中按首页。页大小默认20且无上下限，取 size+1 探测；仅有更多且本页非空时生成末条游标，total 固定 null。
  → 已写入业务动作 A2/A5、详细流程第 3-4、7 步与边界情况

- [Q3] 本人侧、胜负和球员展示快照如何转换？
  > 本人出现于 A 侧即按 A，跨侧重复也优先 A；胜方字段与本人侧一致才算胜，不由分数推断。比分、性别、队友和对手均取比分保存快照，头像签名一小时，日期 MM-dd。
  → 已写入业务动作 A3-A4、详细流程第 5-6 步与实现提示
