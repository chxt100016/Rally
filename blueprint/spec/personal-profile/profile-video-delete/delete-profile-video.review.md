## 已确认

- [Q1] 目标 key 不在档案中或列表含多个相同 key 时如何删除，删除后是否仍保证至少一个视频？
  > 只在删除前断言列表 size>1。removeIf 删除所有相同 key；不存在时列表不变仍删外部文件，重复项会全部移除，删除后可能剩一项也可能为空，不再校验。
  → 已在详细流程、异常说明和技术线索明确无命中仍删文件、重复项全删且删除后不复核。

- [Q2] 档案视频入口是否校验 key 属于本人目录或已登记在本人档案？
  > 不校验。只要求请求 key 非空白，不要求 videos/{userId}/ 前缀，也不确认 key 已登记；可对任意提交 key 调用七牛删除。
  → 已在契约、详细流程和服务边界明确档案入口不校验本人前缀或登记关系。

- [Q3] 七牛文件删除成功后个人档案聚合失败，数据库列表与外部文件如何收场？
  > 列表先保存、七牛再删除、最后 getMyProfile。聚合异常触发数据库事务回滚到旧列表，但七牛文件不能回滚或恢复，因此旧列表可能继续引用已删除文件。
  → 已在详细流程、流程图和异常分支明确聚合失败回滚列表但外部文件不恢复。

- [Q4] 无网球档案、TBC 档案与文件已不存在时分别如何处理？
  > 无基础用户抛 TOKEN_INVALID；有用户无 profile 时空指针系统异常。TBC 可删除并返回仅状态与基础资料。七牛 code 612 视为文件已不存在，继续聚合并成功。
  → 已在异常分支明确无档案失败、TBC 返回范围及七牛 612 成功。
