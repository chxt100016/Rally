## 已确认

- [Q1] 匿名访问与登录用户是否有不同结果或额外鉴权要求？
  > 接口标注 OptionalAuth；匿名和已登录调用均可访问，用户身份不参与查询，结果口径相同。
  → 触发、接口契约与详细流程第 1 步

- [Q2] 开通编码如何分割、去重和排序，空白与重复编码如何处理？
  > 按英文逗号原样 split 后用 Set.copyOf 去重；不 trim，重复值折叠，返回顺序不保证与配置一致。
  → 接口契约与详细流程第 3 步

- [Q3] 未知编码或城市名录缺失时，是过滤、失败还是保留空项？
  > 不校验、不滤除且不报错；Map.get 得到 null，MapStruct 列表映射保留对应 null 元素。城市缓存整体为空时会得到若干 null 项。
  → 接口契约、详细流程第 4-5 步与异常分支说明

- [Q4] 开通配置缺失、停用或读取异常时分别采用什么口径？
  > 无启用覆盖时 SystemConfig 回退枚举默认值 330100,330200；字符串分割发生异常时返回空清单。底层配置缓存或应用初始化失败不提供本接口的降级结果，按系统异常处理。
  → 详细流程第 2 步与异常分支说明
