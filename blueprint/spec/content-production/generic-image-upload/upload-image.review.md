## 已确认

- [Q1] 未指定文件名时如何确定资源标识？
  > 按 Java 实现确认：生成随机文件名，并根据图片开头字节补 jpg、png、gif 或 webp 扩展名；无法识别时按 jpg。
  → 已落入接口契约和详细流程。

- [Q2] 重复上传同一请求是否复用已有图片？
  > 按 Java 实现确认：不做业务幂等；未指定文件名会形成不同资源，指定相同资源位置时直接交由七牛云处理。
  → 已落入触发。

- [Q3] 七牛云保存成功但访问地址生成失败时是否删除图片？
  > 按 Java 实现确认：不删除已保存图片，对外仍按系统异常处理。
  → 已落入异常分支。
