## 已确认

- [Q1] 图片格式如何识别，无法识别、空内容或文件名已有扩展名时如何确定最终扩展名？
  > 只看开头魔数：FFD8=jpg、8950=png、4749=gif、RIFF=webp；不足四字节或不命中统一回退 jpg。指定文件名只要包含任意句点就不补扩展名，否则追加识别扩展名；未指定则生成无连字符 UUID 文件名。
  → 已写入业务动作 A1-A2、详细流程第 1-2 步与边界情况

- [Q2] 目录和文件名允许哪些值，5MB 与图片真实性由活动还是入口校验？
  > 入口要求 file 参数且 multipart 单文件与整请求均不超过 5MB；活动读取全部字节，不再校验大小、非空或 MIME，也不验证内容确为图片。dir 仅去除首尾斜杠，不清理内部路径；filename 不做字符、路径或长度校验。
  → 已写入触发条件、活动契约、详细流程第 3-4 步与边界情况

- [Q3] 上传覆盖、七牛失败和签名地址失败如何收场，成功地址有效多久？
  > 资源 key 由规范化目录和文件名组成；相同 key 的覆盖语义交给七牛，本活动不查重。上传失败直接报系统错误；上传成功后签名失败也报错，但不删除已上传对象。成功地址有效 3600 秒，不持久化本地记录。
  → 已写入业务动作 A3-A4、详细流程第 5-6 步、异常分支与边界情况
