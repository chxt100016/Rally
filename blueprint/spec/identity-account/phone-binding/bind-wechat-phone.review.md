## 已确认

- [Q1] 已有手机号时是否需要二次确认或保留旧值？
  > 按 Java 实现确认：不二次确认，直接用本次微信授权手机号覆盖旧值，也不单独留痕。
  → 已落入触发和详细流程。

- [Q2] 是否校验同一手机号只能绑定一个用户？
  > 按 Java 实现确认：不校验手机号唯一性。
  → 已落入触发、详细流程和服务边界。

- [Q3] 用户资料保存失败时是否保留本次手机号？
  > 按 Java 实现确认：更新运行在事务内，保存失败时本次绑定不成立，原手机号保持不变。
  → 已落入异常分支。

- [Q4] 微信手机号获取失败应统一错误码，还是保留主线区分 WECHAT_AUTH_FAILED(30002) 与 WECHAT_PHONE_NUMBER_FAILED(30003)？
  > 保留主线两种错误码：访问令牌为空为 30002，手机号接口配置或响应失败为 30003；仅动态令牌入参为空使用 PARAM_ERROR。
  → 流程图和异常分支已按 30002/30003 分流。
