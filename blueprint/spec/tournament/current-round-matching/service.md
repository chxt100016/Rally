## 服务边界

本服务通过运营 HTTP 入口或每日定时任务，对赛事已有的当前轮次进行分组并建立比赛。运营可指定赛事、临时排除参赛编号或先落地手工分组；定时任务只扫描已到资格赛开始时间的激活赛事并自动匹配。服务只处理当前轮次的 `WAITING` 报名，完整成组后改为 `IN_MATCH`，并按唯一订场人是否明确创建 `BOOKING` 或 `MATCHED` 比赛。它不保证全部报名均能匹配，不修改临时排除和未成组报名，不推进轮次，不负责后续订场、履约、赛果或赛事结束，也不向触发方返回比赛清单、未匹配原因和通知结果。
