## 已确认

- [Q1] 配置聚合边界是一条 key+scope 记录还是全部平台配置，缓存是否在事务边界内？
  > 每个 configKey+scope 是独立聚合；JVM/分布式缓存是事务外投影，只能在数据库提交后失效或重建。
  → 边界与缓存边界情况

- [Q2] 配置值长度采用应用当前 100000 字符还是数据库 2048 字符上限？
  > 领域契约采用持久化真实上限 2048 字符；结构化 JSON 紧凑序列化后仍超过上限则拒绝，不把数据库异常当参数校验。
  → I3、C1 与长度边界情况

- [Q3] 版本、valueType 与 enabled 在首次发布和更新时如何变化？
  > 首次提交 expectedVersion=0，建立 version=1；更新必须精确匹配并原子加一。valueType 由配置名录定义且不可漂移，发布会置 enabled=true；停用用独立版本化命令。
  → 状态、I2/I4、C1/C2
