## 已确认

- [Q1] 比分记录是否允许不存在或非本场参与者的球员，以及球员快照缺失时能否保存？
  > 不允许。调用方传入约球有效参与者及展示资料结论，所有阵容用户必须存在、属于本场且互不重复；每位球员都要形成昵称/头像/性别快照。
  → 外部引用、I2/I3 与缺失用户边界情况

- [Q2] SINGLE、DOUBLE、RALLY 的阵容人数如何约束？
  > SINGLE 每侧恰好 1 人且 player2 为空；DOUBLE 每侧恰好 2 人；RALLY 每侧可 1 或 2 人但两侧人数必须相等。
  → I2 与阵容边界情况

- [Q3] GAME 与 TIEBREAK 赛制采用什么最小合法计分规则，胜方如何确定？
  > 所有分数非负且不得相等。GAME 接受 6:0-4、7:5、7:6 及对称结果；7:6 时双方抢七分必填且胜方至少 7 分、领先至少 2。TIEBREAK 主分本身至少 7 且领先至少 2，附加抢七字段为空。胜方只由合法分数推导。
  → I4/I5 与计分边界情况

- [Q4] 更新比分的 version 是否必须进入 SQL 条件并递增，删除不存在记录如何处理？
  > 更新必须 WHERE bizId+meetupId+version，成功后 version 原子加一并检查影响行数；版本不符明确冲突。删除按 meetupId+bizId，目标不存在按幂等已删除处理。
  → I6、C2/C3 与并发更新/删除边界情况
