## 已确认

- [Q1] 视频上传授权应保持当前桶级 scope，还是强制限制到 videos/{userId}/ 前缀？
  > 必须使用前缀 scope 且 isPrefixalScope=true，最终令牌不得被 SDK 重写成桶级授权；头像和普通用户图片继续使用精确 key scope。
  → 契约 scopeMode、规则 R2/R3 与视频前缀边界情况

- [Q2] 领域服务是否负责判断资源属于某个用户，以及如何处理含 ..、反斜杠或空段的 key？
  > 调用方传入已确定的允许命名空间，服务校验 key 位于该命名空间且拒绝空白、绝对路径、反斜杠、. 或 .. 路径段；业务所有权仍由调用聚合判定。
  → 职责边界、规则 R1/R6 与非法路径边界情况

- [Q3] 删除不存在对象与签名不存在对象分别返回什么结论，是否与数据库事务做补偿？
  > 删除不存在对象按幂等已删除处理；读 URL 签名不探测对象存在性，只表示签名成功。服务不参与数据库事务，也不承诺外部删除后的恢复补偿。
  → 输出结论、规则 R4/R5 与事务补偿边界情况
