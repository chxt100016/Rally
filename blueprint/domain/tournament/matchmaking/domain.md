## 概要

为赛事当前轮次生成覆盖最多且稳定择优的比赛分组。

## 职责

| 范围 | 内容 |
|---|---|
| 做什么 | 校验并优先采用手工分组；从剩余完整参赛单元中按共同时间、地区和历史对阵约束寻找可行组合；最大化覆盖并按稳定规则择优 |
| 不做什么 | 不读取或保存报名/比赛；不分配 matchNo；不改变报名状态；不发送通知；不修补双打缺员；不持久化临时排除或匹配策略 |
| 为什么不是聚合 | 匹配结果由多个报名快照和跨比赛历史共同计算，没有单个聚合实例能承载该规则，且服务本身无持久状态 |
| 前置校验边界 | 只保证输入快照下分组合法；真正创建比赛和把报名改 IN_MATCH 仍由调用活动在事务内校验并提交 |

## 契约

### 输入

| 字段 | 类型 | 必填 | 约束 |
|---|---|---|---|
| round | 轮次 | 是 | 赛事当前轮次 |
| groupSize | 整数 | 是 | 每场参赛单元数，只接受 2 或 3 |
| candidates | 参赛单元列表 | 是 | 每项以 entryNo 唯一，含完整成员、共同偏好、订场能力、性别构成与报名时间；均已是当前轮 WAITING |
| excludedEntryNos | entryNo 集合 | 否 | 仅本次排除，空集合表示不排除 |
| manualGroups | entryNo 分组列表 | 否 | 每组必须恰有 groupSize 个互异候选，组间不得复用 |
| completedPairings | 历史对阵集合 | 否 | 已完成比赛中同场出现过的无序 entryNo 对 |

### 输出

| 字段 | 类型 | 说明 |
|---|---|---|
| groups | 分组列表 | 手工组在前、自动组在后；每组含 entryNos、共同时间、共同地区和可选唯一订场人 |
| unmatchedEntryNos | entryNo 列表 | 校验后未被任何分组选中的候选，按 entryNo 升序 |

输入结构非法时返回明确拒绝结论；合法但没有可行完整组时返回空 groups，而不是错误。

## 规则

R1 服务只接收完整参赛单元。每个 entryNo 在候选中唯一，双打成员必须齐全；缺员、非 WAITING 或轮次不符的记录应在调用前排除。
R2 先移除 excludedEntryNos，再校验 manualGroups。手工组必须人数完整、编号非空且互异、全部来自剩余候选，组间不得复用；任一不合法则拒绝整个请求。
R3 合法手工组按输入顺序先占用候选，不再参与自动匹配；手工意图可以覆盖自动匹配的偏好和历史择优，但不能绕过身份、完整性与排除约束。
R4 自动组内所有参赛单元必须至少有一个共同可比赛时间和一个共同地区，并且任意两个 entryNo 不得出现在 completedPairings 中。
R5 在满足 R4 的方案中，第一目标是最大化被分组的参赛单元数，不为局部高分组合牺牲整体覆盖数。
R6 覆盖数相同时依次偏好：具备明确订场能力的组合、符合赛事期望的性别构成、较早报名的单元；仍相同时按 entryNo 字典序选择，使相同输入得到相同输出。
R7 一个分组中恰有一个可订场用户时输出其 userId 作为唯一订场人；零个或多个时不指定，由比赛进入 MATCHED 等待认领。
R8 服务是纯计算：不得读取仓储、生成业务 id、修改输入对象或产生通知等副作用。

## 边界情况

- candidates 为空或不足 groupSize：返回空 groups，所有合法候选列入 unmatchedEntryNos。
- 所有候选都被临时排除：返回空结果，排除项不列入 unmatchedEntryNos。
- 手工组引用排除项、未知编号、重复编号或不完整组：整体拒绝，不返回部分手工结果。
- 多个组合共享时间/地区但都违反历史对阵约束：保持未匹配，正常返回。
- 手工组用完后剩余人数不能整除 groupSize：优化可返回若干完整组，余数保持未匹配。
- 完全同分的自动方案：以 entryNo 稳定排序收敛，避免不同实例给出不同结果。

## 实现提示

把 entryNo 对规范化为 `min|max` 形式索引历史对阵；预先计算候选间的时间、地区兼容图，再用受限组合搜索最大覆盖方案。输入规模较大时仍必须保留 R5 的全局覆盖目标，可用分支限界剪枝，但不能退化为遇到即取的贪心算法。
